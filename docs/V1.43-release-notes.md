## 关键情报（护城河视角）
- **官方 Java SDK `mcp-core` 自己有 7.5 DoS CVE（CVE-2026-108395）**：Servlet SSE/Streamable HTTP/Stateless 无限缓冲 body、不校验 Content-Length、单请求 OOM。本框架 `mcp-core`（治理增强层）的 RateLimit + 资源隔离 + 审计正是对此的补偿控制 → 最强「升级 SDK≠安全」叙事。
- **NVD 139 条 MCP CVE（24 Critical / 66 High）**，治理鸿沟持续扩大。
- **长庆/襄阳 10-16 截（明天）**、ZC 10-20 截（5 天）——最后一次提醒窗口。
