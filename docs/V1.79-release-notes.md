# V1.79 Release Notes（2026-11-25）

## 判词

**日志 / 遥测输出面也不是安全边界** —— 十一段式收口第十一段。

前十段（注解 → 注册中心 → 只读声明 → 决策层 → 配置面 → 结果面 → 身份传播面 → 会话/传输绑定面 → 执行环境隔离面 → 浏览器出站响应面）管的都是**调用自身**；V1.79 管一个全漏的方向：**调用合法，但把调用记下来/发出去的动作把凭据、secret 引用和内网拓扑从日志行、指标标签、诊断响应里漏出去**。`redactSensitive=true` 是配置声明、prompt injection 一绕就过，凡离开信任边界的字符串必须在出口按内容独立定级脱敏，默认 fail-closed。

⚠️ 开发中对照组断言抓到并修正 2 处真问题：① 合法对照 C8 `password=<redacted> written to sink` 被误杀——`hasCredential()` 简单替换占位符后把后续普通词当成新口令值，改成"marker 后紧跟 `<redacted>`/`<ref>` 就跳过"的幂等逻辑；② attack #18 夹具文本误含 "error" 字样导致判定误放行、测试假绿，改成无 error 标识的原始帧才真正命中。**「只写顺风测试会选错方案」再验。**

## 诚实边界

- 本框架**不受** IoTDB / AWS ECS / mcp-server-fetch 等第三方 CVE 直接影响。
- 参考守卫**仍在 examples/ 层未接入 21 主模块**；凭据正则 / IP 分类 / allowlist 为可运行演示，生产须由日志框架过滤器 + 配置中心 + SIEM 共同保证；掩码不是加密、日志一旦落盘明文无法靠开关收回（AWS「升级后须轮换凭据」同理）；IP 判定为字面量分类不做 DNS 解析、凭据检测为词法归一化非语义解析、审计表为单进程内存演示。
- 招聘薪资 / 报价为公开挂牌价非成交价；广发四份预征集≠采购邀请、7 项资质不满足只能联合体技术分包、13327 正文无截止须核实；华安证券/上海银行两个智能体标未点名 MCP 不计入可投清单；本项目无企业主体/合同/中标/金融案例/等保测评；Spring AI 2.0 未升级。
