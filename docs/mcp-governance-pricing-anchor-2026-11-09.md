## 一、一句话结论（背下来）

> **裸 MCP server 的市场均价是 $0；加一行鉴权卖 $8K–25K；加上 audit / SSO / RBAC / 多租户 / 可观测卖 $80K–220K；做成集中式企业网关 $250K 起。**
> 代码量没有增加 10 倍，**增加的那部分是治理层**。所以不要报「做一个 MCP server」的价，要报「交付一套能通过数据保护审查的治理底座」的价。

## 二、公开报价梯度（同一范围，19 倍价差）

「小型只读连接器」范围：≤10 工具 / 1 个系统 / 内部员工使用 / 单 API Key / Streamable HTTP。

| 档位 | 报价 | 来源 |
| --- | --- | --- |
| 最低 | **$3,700 – $9,800** | BeevR 认证只读 @ $31–41/h（东欧，3–6 周） |
| 中低 | **€5,000** | mcp-agency.com「MCP Foundation」单域单环境 |
| 主流 | **$8,000 – $15,000** | ScalaCode 单系统 5–10 工具；Make An App Like Basic MVP |
| 主流+ | **$8,000+** | AppMatic Tech 单数据源集成 |
| 中高 | **$12,000 – $35,000** | Clyrix Digital「Basic production」1–2 个 SaaS |
| 最高 | **$12,000 – $72,000** | BeevR 同范围 @ $100–300/h（欧美） |
| 按工时折算 | **$28,080 – $132,400** | 43.9–82.8 person-days（9–17 周）× $80–200/h |

**工作量拆解（Dawloom 发布的 work packages）**：Discovery 5–10 人日 / 语义层与工具规约 8–15 / scaffold·transport·deploy 5–10 / 6 个读工具 9–18 / API Key auth 1.9–3.8 / 测试 10–18 / 文档与交付 5–8。
**关键规则（该工具自己标为「ours」）**：① 每多接一个系统，**重复一次「语义层 + 工具规约」工作包**；② **一旦 server 能写数据或面向客户，必须追加 audit logging 工作包**。

> ⚠️ 报价离散度 19 倍说明这些是**卖方销售页**而非市场成交价。Dawloom 自述「没有独立的 MCP 造价调研，绝大多数发布者自己就卖 MCP 搭建服务」。**议价时用它做上界/下界，不要用它做成本依据。**

## 三、★ 治理层 10 倍定律（本期最值钱的一张表）

| 范围 | 报价 | 工期 | 新增的到底是什么 |
| --- | --- | --- | --- |
| 简单单工具 server | $3,000 – $8,000 | — | 无鉴权 |
| 加 auth 与权限 | $8,000 – $25,000 | — | **基础鉴权** |
| 单系统专用 | **$15,000 – $45,000** | 1–4 周 | 连接 1 个内部系统 |
| 多系统 + 写权限 | $35,000 – $90,000 | — | 多系统集成 |
| **生产级内部产品** | **$80,000 – $220,000** | 8–16 周，2 工程师 + 兼职平台 lead | **audit logging / SSO / RBAC / versioning** |
| **企业网关** | **$250,000 起** | 16–32 周 | **集中 auth / 策略执行 / 跨团队可观测** |
| 自建总成本带 | **$15,000 – $220,000 + 每年 10–30% 运行成本** | — | — |
| 全负载口径 | **$50,000 – $150,000 / 集成 / 年** | — | Truto：含开发/QA/监控/支持 |
| 启动费 | scoping **$2,300 – $4,700**；首 workflow **$17,500 起** | — | Reflekt Lab（公开报价的 agency） |

**本框架 21 模块 → 溢价带的逐项对位（投标时逐行引用）**：

| 溢价要素 | 本框架现成模块 / 文件 | 验收证据 |
| --- | --- | --- |
| SSO / OAuth 2.1 资源服务器 | `mcp-auth`（Bearer 强制校验 + jti 防碰撞 + 吊销端点） | 无效 token / 错 `aud` 必须 401 |
| RBAC / 逐工具权限 / HITL | `mcp-governance`（Scope-ACL、人类在环审批、参数校验 fail-closed） | 越权工具调用必须拒绝并留痕 |
| Audit logging（不可篡改） | `mcp-audit`（`JdbcGovernanceAuditSink` / `McpAuditLogger` append-only） | 生成内容与工具调用可回溯到人与参数 |
| 多租户隔离 | `mcp-tenant`（`McpTenantFilter` / `TenantContext` / `TenantAwareJdbcTemplate`） | 跨租户查询返回空集 |
| 可观测 / 告警 | `mcp-monitor` + [`examples/monitor-alert-rules/`](../examples/monitor-alert-rules/README.md)（Prometheus 4 组 15 条 + `mcp_security_*` 10 指标） | 拒绝分支必须产生指标与告警 |
| Versioning / 注册中心 | `mcp-registry` + `mcp-gateway`（工具注册、默认 disabled、动态列工具） | 未审核工具不出现在列表 |
| 合规工件（ROPA 七字段） | [`examples/audit-ropa-export/`](../examples/audit-ropa-export/README.md) | JSON/CSV 导出 + 完整性自检 |
| 连接路径准入（官方不管的一层） | [`examples/connect-path-guard/`](../examples/connect-path-guard/README.md) + 本期 `McpResolvedIpGuard` | `$(...)` 载荷、私网/元数据 IP 必须拒绝 |

> **售前话术（照抄）**：「你们拿到的 $15K 报价是『把系统接上』，我们报的是『让这套接入通过数据保护审查并留下可审计证据』。Strac 的 8 家网关横评里写得很清楚：**如果 enterprise 意味着适配既有采购合同，云巨头赢；如果意味着通过数据保护审查，候选名单短得多**。我们做的就是让后者变短的那部分。」

## 五、三档报价模板（把上面的锚变成可发出的数字）

> 仅为**锚定结构示例**，实际报价须按买方范围、工期、资质、私有化/等保/密评要求重算；切勿在资质不足时承诺交付。

| 档 | 对应范围 | 锚定区间 | 交付物（挂本框架模块） | 适用买方 |
| --- | --- | --- | --- | --- |
| **A · 接入** | 单系统 / ≤10 只读工具 / 单租户 | $8K–15K（国内按人日折算） | 工具注册 + 参数校验 + 基础鉴权 + 文档 | 内部试点、POC |
| **B · 生产** | 多系统 / 含写操作 / 需审计 | **$80K–220K** | A + SSO/RBAC/逐工具 ACL/HITL + 不可篡改审计 + 多租户 + 可观测 + ROPA 导出 | 银行 / 券商「底座期」平台、广发 13322 |
| **C · 网关** | 跨团队集中治理 | **$250K 起**（对齐国内 ZC26G280436 683 万中标口径） | B + 集中策略执行 / 联邦注册 / 默认 disabled / 按 caller 授权 / 跨运行时签字 | 央企、集团级平台、山东重工 |

**三档共用的加价触发器**（每命中一条就升档，写进 SOW 边界）：能写数据 / 面向外部客户 / 接第二个系统 / 需 SSO / 需多租户 / 需不可篡改留痕 / 需等保三级或密评 / 需私有化不上云 / 需对接买方指定 Dify·hiagent 等第三方运行时。

## 六、诚实边界（必须随报价一起说明）

- 上述全部是**卖方销售页 / 行业估算 / 平台公开时薪**，**无一是本框架已成交的合同价**；本项目目前**没有任何商业合同或中标记录**。
