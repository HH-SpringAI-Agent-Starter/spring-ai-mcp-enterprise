# V1.9 Release Notes — OAuth2 Refresh Token 轮换 + 网关 Bearer 自动校验

> 发布日期：2026-08-21 | 代号：**Token 轮换（Token Rotation）**
> 主题：让企业 M2M 凭证体系达到「生产可审计」级别——短期令牌 + 轮换刷新 + 重用检测 + 网关强制校验

## 一、背景

V1.8 落地了 OAuth2 Client Credentials + EMA 企业集中授权（回应市场调研的 #1 痛点：统一鉴权）。

但企业落地还有两个「最后一公里」问题：

1. **access_token 过期后怎么办？** 长期驻留的 AI Agent（定时任务、企微机器人、后台批处理）如果每次都用
   client_secret 重新换 token，等于把长期密钥暴露在每台机器上；不换又会在 1 小时后中断。
   业界标准答案：**Refresh Token 轮换**（OAuth 2.0 Security BCP，RFC 9700）。
2. **网关层如何强制校验？** 不能指望每个业务 Controller 自己调 `validateToken`——需要**网关级的 Fail-Closed
   Bearer 自动校验**，一次配置、全部端点生效。

## 二、新增功能

### 1. Refresh Token 轮换 + 重用检测（mcp-core `McpOAuth2Manager`）

- `issueClientCredentialsToken` 现在同时签发 `access_token` + `refresh_token`（30 天有效，可配置）
- 新增 `refreshClientCredentialsToken(clientId, secret, refreshToken)`：
  - **轮换**：每次刷新换发全新 access+refresh 对，旧 refresh 立即作废
  - **重用检测**：已轮换的 refresh token 再次出现 → 判定泄露 → **整族吊销**（该家族所有已签发 token 全部失效）
- 新增 `revokeRefreshToken()`（RFC 7009 吊销语义）
- 新增 `getRefreshTokenCount()` 统计
- refresh token 仅存 SHA-256 散列，数据库泄露也无法反推（同 client_secret 策略）
- **附带修复**：access_token 增加全局唯一 `jti` 声明——此前同一秒内为同一 client 签发的 token 字节相同（碰撞风险），现已唯一

### 2. Token 端点扩展（mcp-server `McpOAuth2Endpoint`）

| 变化 | 说明 |
| --- | --- |
| `POST /oauth2/token` | 新增 `grant_type=refresh_token`；client_credentials 响应新增 `refresh_token` |
| `POST /oauth2/revoke` | 新增 RFC 7009 吊销端点（access_token / refresh_token，恒返 200 防探测） |
| `GET /oauth2/introspect` | 不变（RFC 7662） |

### 3. 网关 Bearer 自动校验过滤器（mcp-server `McpBearerAuthFilter`）

- 配置 `mcp.enterprise.security.oauth2.enforce-bearer=true` 开启（默认 false，平滑迁移）
- 所有非公开路径强制 `Authorization: Bearer` 校验，**Fail-Closed**：无效/缺失 → 401 + `WWW-Authenticate: Bearer`
- 校验通过后 TokenInfo（clientId/scopes/roles）写入 `request attribute: mcp.tokenInfo`，下游可做 scope/RBAC 二次鉴权
- 自动放行：`/oauth2/**`、`/api/mcp/health`、`/actuator/**`、`/error`、OPTIONS 预检
- 平滑迁移：存量 `X-API-Key` 客户端不受影响（校验失败的 Bearer 仍 fail-closed）

### 4. 配置新增（`mcp.enterprise.security.oauth2.*`）

```yaml
mcp:
  enterprise:
    security:
      oauth2:
        signing-key: ${OAUTH2_SIGNING_KEY}
        token-ttl-seconds: 3600              # access token 1 小时
        refresh-token-ttl-seconds: 2592000   # refresh token 30 天
        enforce-bearer: false                # true = 网关强制 Bearer 校验
```
