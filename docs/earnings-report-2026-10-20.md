## 🛡️ 五、安全 / CVE 护城河（今日最强：最硬批评者倒戈 + 事实标准坐实）

### 5.1 MCP 成 de facto standard（治理增强层定位被生态坐实）
- **Pi 1.0（10-14）把原生 MCP 装进核心**（Code Mode + 原生 MCP stable）——其创始人曾公开嘲讽 MCP，"连最硬的反对者都倒戈"。
- **Atlassian 重建 MCP Server GA：220+ 工具 / 1500 万次/日**，AMP 框架给 agent 发"非人类身份 + 审计"。
- 事实标准数据：**78% 企业 AI 栈 / 4 亿+ 月 SDK 下载（Anthropic 7-28 口径）/ 15,930+ 公开服务器**；Google Cloud Agent Gateway 原生支持；Linux Foundation Agentic AI Foundation 治理。

### 5.2 10 月 CVE 集群（"认证≠授权 / 升级官方 SDK≠安全"再实锤）
- **Adversa AI 10 月 digest**：**OWASP MCP Top 10（beta）10 类攻击**（token 泄露 / 权限提升 scope creep / 工具投毒 / 供应链 / 命令注入 / prompt 注入 / 认证授权不足 / 审计缺失 / 影子 MCP / 上下文过度共享）。
- **MCPTox benchmark**：45 个 live server / 353 工具，投毒成功率 **36.5% 平均、最高 72.8%**（模型越聪明越易被投毒）→ 工具描述审查 + 默认 deny 是刚需。
- **LiteLLM MCP 端点仍居 CISA KEV**（CVE-2026-59822，接受任何无效 bearer token → 云接管）。
- **Grafana MCP 会话伪造 SSRF**（CVE-2026-19516）、**Obot 网关 deny-list 绕过**（/mcp-connect-composite/ 漏网）、**Langflow MCP Stdio RCE**（CVE-2026-105740）、**Cycode MCP Python SDK 账户接管**（legacy fallback 跳 issuer 校验）。
- **82k 公开 MCP 配置硬编码密钥**（9.6% 代理仍用默认 sk-1234）。
- **官方 Java mcp-core 7.5 DoS**（CVE-2026-108395）仍在；**官方 Kotlin SDK 内存耗尽 DoS**（CVE-2026-108714，无修复）；**Fetch SSRF**（CVE-2026-104120，无修复）。
- **CoSAI 安全模型 v2.0** 发布；"Five gates before an MCP tool reaches production"（trace credential / scope / rate-limit / HITL / audit）清单与本框架 T0–T4 + HITL + JDBC 审计范式一一对应。
