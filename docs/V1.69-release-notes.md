```
McpToolAnnotationGate  : self-test OK (17 attack cases + 9 control cases + 6 boundary assertions) / 32 assertions
```

两个示例均为**纯 JDK 零依赖、不进 reactor 零构建风险**，且都含「**不得劣于既有基线**」对照组断言。开发过程中断言抓到两处逻辑错误并修正：① 诚实声明 `destructiveHint=true` 的删除工具应「允许注册但强制审批」，而非拒绝注册；② 审计脱敏若只替换字段名，会把明文值留在串里 —— **只看「拦得更多」或只看「误报更少」都会选错方案**（本项目工程约定再验）。
