## 🔧 工程实测（不进 reactor，零构建风险）

```
javac -encoding UTF-8 -d out examples/read-only-enforcement/McpReadOnlyEnforcementGate.java
java -Dfile.encoding=UTF-8 -cp out com.example.mcp.readonly.McpReadOnlyEnforcementGate
[McpReadOnlyEnforcementGate] self-test OK
  (22 attack + 9 control + 8 boundary = 79 assertions; 20 incremental blocks over legacy baseline)
CP1 lex  CP2 bind+tx  CP3 session  CP4 origin  CP5 env  CP6 path/ip
```

| CP | 控制点 | 拒绝码 |
| --- | --- | --- |
| CP1 | 词法归一化 + 全文动词扫描 + 堆叠计数 + dollar-quote 逃逸 | `MULTI_STATEMENT_*` / `WRITE_VERB_*` / `DOLLAR_QUOTE_TAG_ESCAPE` / `UNCLOSED_*` |
| CP2 | 强制参数绑定 + 服务端只读事务 + where 作用域 | `FORCE_BIND_REQUIRED` / `NO_SERVER_SIDE_READ_ONLY_TRANSACTION` / `WHERE_SUBQUERY_OUT_OF_DECLARED_SCOPE` |
| CP3 | 池化会话状态复位 | `POOLED_SESSION_STATE_NOT_RESET` |
| CP4 | Origin 白名单 / Host 一致 / 身份不取最左 XFF | `ORIGIN_MISSING_OR_UNTRUSTED` / `HOST_ORIGIN_MISMATCH_DNS_REBINDING` / `IDENTITY_FROM_CALLER_SUPPLIED_LEFTMOST_VALUE` |
| CP5 | 禁止加载仓库自带可执行配置 | `READONLY_TOOL_LOADS_UNTRUSTED_REPO_CONFIG` |
| CP6 | 校验/实际路径同源 + 解析后 IP 分类完整 | `VALIDATED_PATH_NOT_SAME_AS_ACTUALLY_FETCHED` / `SSRF_IP_CLASSIFIER_GAP_*` |

**20 条增量拦截**＝旧基线「看 `readOnlyAnnotation` + 首关键字 SELECT/WITH 就放行」
全部错误放行、执行层门全部拦下的真实载荷形态。**9 条合法只读对照全部放行**
（字符串内关键字/分号、dollar-quote、内联注释、只读 CTE、双引号标识符），
含「不得劣于既有基线」断言 —— 只演示拦截量而误杀正常业务的方案不算工程能力。

> `.allowed()` 调用编译失败 → 统一改为字段访问后 79 断言全绿。

## ⚠️ 诚实边界

1. **本框架不受** pgEdge 7 CVE / 官方 5 GHSA 直接影响（不内置这些实现）；引用为
   **行业级失效模式**与买方验收口径。
2. 12 项验收清单是**参考实现的验收口径**：CP2 where 作用域 / CP3 会话状态 /
   CP4 身份来源 / CP5 环境净化 / CP6 路径 IP 在示例中以**执行上下文标志**表达，
   用于演示 fail-closed；真实落地需接 JDBC/pgx 元数据、连接池 hook、可信代理头、
   DNS 解析后 IP 分类器。**不得把示例当生产组件交付或宣称已内置主模块。**
3. 参考实现**未接入** `mcp-core` / `mcp-registry`；`mcp-monitor` `exportPrometheus()`
   挂 actuator、dataClassification 差异化审批引擎、Spring AI 2.0 升级均**未完成**。
4. 广发四份为**预征集 ≠ 采购邀请**；本项目 7 项资质门槛**全不满足**，只能联合体
   技术分包，禁虚构企业主体 / 合同 / 案例 / 等保证书。
5. 全部报价为公开挂牌 / 销售页价，**非成交价**；嘉信理财 MCP 当前仅接 Claude、
