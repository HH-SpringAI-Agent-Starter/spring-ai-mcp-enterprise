## ✨ 新增功能

### 1. 通用 HTTP 调用工具（mcp-tools/tool-http）🆕

企业 MCP 最常见的落地场景：让 AI Agent 调用企业内部/外部 REST API（订单、库存、CRM 等）。

**安全设计（防 SSRF）：**
- 域名白名单 `mcp.tool.http.allowed-hosts`，支持 `*.internal.corp` 通配；未配置默认仅 localhost
- 仅允许 GET/POST，禁止 DELETE 等危险方法
- 请求头白名单透传（content-type/authorization/x-api-key/accept）
- 响应体大小上限（默认 1MB），防内存耗尽
- 连接/读取超时独立可配

**使用示例：**
```yaml
mcp:
  tool:
    http:
      enabled: true
      allowed-hosts:
        - api.example.com
        - "*.internal.corp"
      connect-timeout: 5s
      read-timeout: 30s
```

测试：8 个单元测试（含 SSRF 拦截、白名单通配、方法校验）。

### 2. OAuth2 Client Credentials 认证（mcp-auth）🆕

符合 OAuth 2.0 RFC 6749 §4.4 与 MCP Enterprise Auth 规范的**机器对机器（service-to-service）授权**——AI Agent / 集成服务用 client_id + client_secret 换取访问令牌，无需用户交互。

**端点：** `POST /api/auth/oauth2/token`
```bash
curl -X POST http://localhost:8081/api/auth/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=mcp-service&client_secret=change-me-client-secret&scope=tools:read"
```

**响应：**
```json
{ "access_token": "...", "token_type": "Bearer", "expires_in": 3600 }
```

- 支持注册多个服务账户（`registerServiceAccount`）
- 默认账户 `mcp-service`（生产环境必须修改默认密钥）
- 测试：5 个单元测试（成功/错误密钥/未知客户端/不支持 grant type/自定义账户）
