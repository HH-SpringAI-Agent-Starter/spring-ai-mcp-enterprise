## 7. 常见问题

### Q: 我不懂 MCP，能接单吗？

**能。** MCP 协议非常简单，核心就是 JSON-RPC over HTTP。你已经有 Spring Boot 经验，花 2 天读一遍 `spring-ai-mcp-enterprise` 的代码就能上手。

### Q: 客户问"用 Python 还是 Java"怎么办？

**说 Java。** 然后解释优势：
1. 企业级安全（Spring Security）
2. 无缝集成现有 Java 后端
3. 生产级可靠性（JVM 生态）
4. 不需要额外的 Python 运维

### Q: 第一单怎么拿到？

1. 在 Upwork 搜索 "MCP server"，按最新排序
2. 找到预算 $300-$800 的小项目
3. 提交提案时附上 GitHub 项目链接
4. 强调 "enterprise-grade Java/Spring Boot" 差异化

### Q: 收入能到多少？

| 阶段 | 月收入 | 时间投入 |
|------|--------|---------|
| 起步期（1-3 月） | $2,000-$5,000 | 兼职 |
| 成长期（3-6 月） | $5,000-$15,000 | 全职 |
