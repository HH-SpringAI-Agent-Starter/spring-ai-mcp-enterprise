# V1.6 Release Notes — Spring AI MCP Enterprise

> 版本：V1.6 | 日期：2026-08-19 | 状态：已完成

## 版本说明

V1.6 是 **V1.5「网关友好标头」特性的落地增强版**：把 `Mcp-Method` / `Mcp-Name` 标头从"协议能力"变成"可观测数据"。API 网关现在可以通过监控端点直接查看每个操作的调用量、延迟、错误率，实现真正的按操作限流/授权决策。

## 本轮变更内容

### 1. 📊 网关路由指标采集（Gateway Route Metrics）
- **新增**：`McpMetricsCollector.recordGatewayInvocation(method, name, latencyMs, success)`
- **维度**：按 `Mcp-Method`（tools/call、tools/list、ping…）+ `Mcp-Name`（工具名）双维度聚合
- **统计**：调用量、错误数、错误率、p50/p95 延迟、成功/失败计数
- **上限保护**：`MAX_GATEWAY_OPS = 500`，防止恶意标头导致内存无限增长
- **未知兜底**：空/缺失标头归一到 `unknown`，保证聚合键安全

### 2. 🛡️ McpStatelessController 埋点
- 路由验证失败（`validateGatewayHeaders` 拒绝）→ 记录失败指标（success=false）
- 正常处理 → 记录耗时与成功状态
- `@Autowired(required = false)` 注入：mcp-monitor 不在 classpath 时静默降级，不破坏现有部署

### 3. 🎛️ 监控端点新增
- `GET /api/monitor/metrics/gateway` — 网关路由指标快照（按操作聚合）
- `DELETE /api/monitor/metrics/gateway` — 重置网关指标（便于巡检脚本/压测）

### 4. 🐳 Dockerfile Java 17 对齐修复
- 构建镜像 `maven:3.9.9-eclipse-temurin-17-alpine`，运行镜像 `eclipse-temurin:17-jre-alpine`
- 与项目 `java.version=17` 严格一致（原 26/25 版本与项目脱节）
- 补全 `mcp-auth`、`tool-http`、`tool-finance`、`mcp-alibaba`、`mcp-client-spring-ai` 的 pom 预拷贝
- 使用 `-pl mcp-server -am` 只构建 server 及其依赖链，避免可选集成模块拉取额外仓库

### 5. 🧩 mcp-examples 组件扫描修复
- `McpSpringAiClientApplication` 合并 `springai` 包的 `@ComponentScan`，消除重复启动类
- 删除重复的 `springai/McpSpringAiClientApplication.java`

```
   ▼

   │                          │
   ▼                          ▼

                              │
                              ▼
                    GET /api/monitor/metrics/gateway
```
