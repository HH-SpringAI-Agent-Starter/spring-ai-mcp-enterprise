## 二、为什么今天做"持久化"而不是别的功能

变现路径决定功能优先级。三个正在变现的入口都需要"**状态可持久、可灰度、可回滚**"：

1. **Upwork "Skills Platform Architecture (MCP)"**（昨天发布，Hourly 1–3 月）：项目明确要"把一次性客户交付变成共享 skills 库 + 多租户 SaaS"。**没有持久化的 registry，就没有多租户 skills 库。**
2. **沃尔玛中国 ¥30–55K/月岗**：JD 要 "Skill、Spec Registry 服务，AI 核心资产可沉淀"。**"沉淀"= 持久化。**
3. **企业 MCP Gateway 顾问单（$102K/yr 等）**：灰度发布 + 回滚是网关治理标配，重启即丢的方案过不了面试/方案评审。

所以 V1.22 是**直接对着钱做的功能**，而不是"顺手加个数据库"。
