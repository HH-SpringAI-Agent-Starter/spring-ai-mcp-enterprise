## 本次变更

### 1. 版本号统一 0.15.0 → 0.16.0

**问题**：V0.16 功能已提交，但 13 个 pom.xml 仍停留在 `0.15.0-SNAPSHOT`，版本不同步。

**修复**：`scripts/bump-version.ps1`（可复用脚本）批量升级全部 pom：
- 根 pom + mcp-core / mcp-server / mcp-auth / mcp-monitor / mcp-spring-boot-starter
- mcp-integrations/mcp-alibaba + mcp-examples/mcp-client-spring-ai
- mcp-tools 全部 5 个工具模块（tool-calculator/database/search/system/weather）

### 2. mcp-alibaba 补 application.yml 示例配置

**问题**：mcp-alibaba 模块 resources 下只有 META-INF，无配置文件示例，用户不知如何配置。

**新增**：`mcp-integrations/mcp-alibaba/src/main/resources/application.yml`
- DashScope API Key 配置（qwen-max / text-embedding-v3）
- `mcp.enterprise.integration.alibaba.*` 全部 8 个配置项带注释
- MCP Server 安全配置 + 日志级别
- 三种使用方式说明（参考/集成测试/全量构建 -Pfull）

### 3. README 加强 Alibaba 集成章节

从一句话扩为完整模块：依赖引入 + yaml 配置 + 自动连接说明 + `-Pfull` 构建命令 + 文档链接。
