# V1.27 Release Notes — 2026-09-18

## 版本主题：Release 工程修复 + Go 客户端示例 + 市场雷达 09-18

> 一句话：**让「克隆即用」承诺重新成立** —— 修复 V1.26 引入的 Docker/CI 失效，
> 补齐 Go 客户端示例，完成 09-18 市场情报。

## 变更内容

### 1. 修复 Dockerfile（关键 Bug）
- **问题**：V1.26 新增 `mcp-governance` 模块后，`mcp-server` 依赖了它，但 Dockerfile 的
  `COPY */pom.xml` 列表没有同步 —— `docker build`（`-pl mcp-server -am` 需解析依赖链 pom）必然失败；
- **修复**：补上 `mcp-governance` / `mcp-gateway` / `mcp-springai-tools` 三个 pom 的 COPY；
  Docker 多阶段构建恢复可用；
- **影响**：`docker-compose.yml` 与 CI Docker job（ghcr.io 镜像推送）恢复端到端可用。

### 2. 修复 GitHub Actions 产物清单
- **问题**：`.github/workflows/maven-ci.yml` 的 artifact upload 与 Release 附件
  缺少 V1.25/V1.26 新增模块 JAR（mcp-gateway / mcp-governance / mcp-a2a / mcp-springai-tools），
  CI 产物不完整，Tag 发布附件缺模块；
- **修复**：upload-artifact 与 gh-release 的 files 清单补齐为全量 19 个构建产物路径。

### 3. 新增 Go 客户端示例（examples/client-go）
- **`mcp_client.go`**：零第三方依赖（仅标准库 `net/http` + `encoding/json`，Go 1.21+），
  与 Java/Node/Python 客户端同构：health / connect / disconnect / list_tools / get_tool /
  invoke_tool / stats 全链路演示；
- **`go.mod`**：`module mcp-enterprise-client-go` / `go 1.21`；
- **价值**：Go 是 Lifted（Upwork #132811，Java/Go 二选一）、Ciena 等岗位点名语言；
  至此客户端示例覆盖 **Java / Node.js / Python / Go 四种语言**。

### 4. 市场雷达 09-18（docs/market-research-2026-09-18.md）
- **新岗位**：OneSeven（Java + Spring Boot/WebFlux + MCP 生产经验，**$4-5K/月**，要求 GitHub 作品）、

  **¥30-55K/月**，11-03 截止）、Ciena Co-op、MintMCP、Descope、Micro1（$60-120/h，100 名额）；
