# V1.2 Release Notes — Spring AI MCP Enterprise

> 版本：V1.2 | 日期：2026-08-11 | 状态：开发中（本轮完成第一步）

## 版本说明

V1.2 是本项目从"核心框架完备"迈向"生态就绪"的版本。本轮完成 **V1.2 第一步：Spring AI Alibaba 集成模块纳入默认构建**，同时补强市场情报与 SEO 内容。

## 本轮变更内容

### 1. 🎯 Spring AI Alibaba 集成模块纳入默认构建 ✅
- **背景**：mcp-integrations/mcp-alibaba（DashScope/DashVector 集成）与 mcp-examples/mcp-client-spring-ai（Spring AI Client 示例）此前需 `-Pfull` 显式激活，新用户默认构建拿不到 Alibaba 集成能力，与"用户技术栈是 Spring AI Alibaba"的项目定位不符
- **变更**：
  - `pom.xml` 默认 `<modules>` 加入 `mcp-integrations/mcp-alibaba` + `mcp-examples/mcp-client-spring-ai`
  - 移除默认构建中对该两模块的注释屏蔽
  - `full` profile 保留（向后兼容历史命令），仅保留 spring-boot-maven-plugin skip 行为
- **依赖说明**：spring-ai-alibaba-starter 1.0.0-M6.1 需要 spring-milestones + aliyun 仓库，已在根 pom 全局 `<repositories>` 声明，默认构建即可解析
- **构建验证**：`mvn clean install -DskipTests` → **15 模块全 SUCCESS**
  - 新增验证模块：mcp-alibaba ✅ / mcp-client-spring-ai ✅
