### 2. W3C Trace Context Middleware 🆕

```java
// Auto-extract traceparent/tracestate from HTTP headers
// Full-chain tracing: AI Agent → MCP Server → downstream tools
McpTraceContext.extractOrGenerate(headers);
```

### 3. Server/Discover REST Endpoint 🆕

`GET /api/mcp/discover` — Returns complete Server capability manifest:
- Protocol versions, tool count, transport modes
- Cache strategy, rate limits
- Health status, uptime
- Auto-discovery ready for MCP Marketplace / Gateways

- Pricing strategy recommendations
