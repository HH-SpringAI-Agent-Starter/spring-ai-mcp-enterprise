> **规格进基金会，责任还在集成方。** MCP 与 Agent Skills 归入 Linux Foundation · AAIF 厂商中立治理后，规格变更不再有单厂商补丁通知，可能更快、从更多方向改变 agent 权限与工具访问边界；但**规格定义「怎么连」，从来不定义「谁能动」**。
> 唯一可验收的边界仍是：按当前任务签发、在工具调用本身机械执行、fail-closed 的确定性执行门。

### 本期证据链（11-13~11-15）

1. ⭐⭐ **AAIF 厂商中立治理的采购含义**：规格版本须作受监控依赖、变更后全量复验、旧审批不继承、采购模板须要求披露 MCP / Agent Skills 规格版本依赖（AI Governance Institute / Google Open Source Blog / 协议地图 11-08 核对）。

4. ⭐ **pgEdge `CVE-2026-126197` 官方细节**：**simple query protocol 让注入携带额外语句与事务控制，绕过 `read_only`** → 精确验证 V1.71。
5. ⭐ **DE-CIX MCP server 门测试 A/B**：句子形式「procure and deploy without asking first」拿 **0.803 auto-act** 放行，「operator confirmation」0.8488 仍放行；scope 形式同动作 0.50 advisory hold → 原文「**enforce the allowlist mechanically on the tool call itself; ... never as the lock**」→ V1.72 确定性执行门论断的独立第三方实证。

## 3. 工程实测

```
cd examples/gate-orchestration
javac -encoding UTF-8 McpGateChain.java && java McpGateChain

attack=84 control=26 boundary=13 TOTAL=123
legacy baseline missed 9 attack cases (new chain blocks all)
failures=0
SELF-TEST OK (pure JDK, zero dependency, all groups green)
```

- **84 攻击全拦 / 26 合法对照 0 误杀 / 13 边界**；JDK 17.0.8 实测。
- 对照组刻意包含：字符串内 `DROP TABLE`、只读 CTE、普通注释里的写动词与分号、带敌意 prose 但 scope 正确的合法只读、`write` scope 下真正合法的 `UPDATE`。
- **「不得劣于旧基线」断言**：旧基线（信 hint + 模型自证 + 首关键字 + URI 前缀 + 跨版本继承审批）漏掉 9 条攻击，新链全部拦下；任一合法对照被误杀即整组失败。
- ✅ **兑现 V1.72 待办④**：按 `docs/gate-integration-map-2026-11-14.md` 分期①给出两个 SPI + `GateChain` 装配 + 端到端回归（**但仍未改主模块**，见诚实边界）。

### 开发中被断言抓到并修正的 3 个真 bug

| # | 问题 | 修正 |
| --- | --- | --- |
| 1 | `normalizeSql()` 移除块注释后，MySQL `/*!` **可执行注释**的 payload 一起消失 | 改用**原始文本**先判 `hasExecutableComment()`；同时把「普通注释里含写动词」改判为**合法对照**（注释里的 SQL 不执行） |
| 2 | RFC 5737 文档专用 IP `203.0.113.24` 被当成合法公网样本 | 换真实可路由地址，新增断言**拒绝**文档段（与 `GHSA-3rxj` IPv6 site-local 误判 public 同型） |
| 3 | 短路断言初版传的是**合法** DCR，实际走到调用期才 DENY | 换成跨租户导入，才真正验证「在配置面短路、不进入调用期」 |

> **「只写顺风测试会选错方案」第 N 次应验**：对照组与「不得劣于基线」是硬要求。

## 6. ⚠️ 诚实边界

- 本框架**不受** IBM / n8n / pgEdge / AWS / VS Code 等第三方 CVE 直接影响；`examples/` 是对其攻击范式的独立参考实现。
- 四 Gate 与本期装配链**仍在 `examples/` 层、未接入 21 个主模块**；`TaskGrant.signatureOk` 是布尔标志**非密码学签名**；IP 判定是字面量分类非 DNS/SNI 逐跳校验；SQL 筛查是词法归一化非解析器；审计脱敏字段白名单为固定常量集。
- **DE-CIX 门测试**为第三方启发式评分实验（`calibrated=false`、作者自报、单次测量、10-19 实测），非近 3 天事件、**非本框架实测拦截率**；123 断言是本仓库自检输出，非第三方测评。
- arXiv 数字（V1.72）为学术模拟实验，非生产拦截率；WhiteMatter（11-10）/ Cisco（10-26）/ Nacos 3.3.0（10 月底）作背景，非近 3 天。
- 全部报价 / JD 标价 / 预算为公开挂牌或预算上限，**非成交价**；OpenAI×Upwork 为相关性分析非因果。
- 本项目无企业主体 / 商业合同 / 中标 / 金融案例 / 等保测评；Spring AI 2.0 **未执行升级**；`exportPrometheus()` 挂 actuator、`dataClassification` 差异化审批引擎、重定向逐跳 SNI 证书校验仍为跨期待办。
