## 1. 核心叙事：六段式收口的第六段

| 版本 | 判词 |
| --- | --- |
| V1.69 | 注解不是安全边界 |
| V1.70 | 注册中心自己也不是安全边界 |
| V1.71 | 只读声明也不是安全边界 |
| V1.72 | 审批与提示词护栏本身也不是安全边界 |
| V1.73 | 配置面 / 连接建立期也不是安全边界 |
| **V1.74** | **工具返回给模型的结果 / 输出面也不是安全边界** |

> **协议治理权上移了，但「回传什么、写到哪、连到哪、拼成什么命令」没人替你管。**
> 前五段管「谁能动 / 怎么判」，第六段管**动完之后交出去的东西**：回传字段、写出文件、外发端点、拼接命令。`readOnlyHint` 与注解、审批弹窗、模型自证一样，**只进审计、不进允许分支**。

### 本期证据链（11-15~11-17）

1. ⭐⭐ **REBUILD `CVE-2026-129875`**：MCP QueryRecords 把 `User.password` 当可过滤字段，count 响应当**盲注 oracle**，低权限用户逐字符恢复管理员 SHA-256 口令哈希并登录管理员（CWE-202）→ 「只读查询的结果也能泄密」。
2. ⭐⭐ **AWS 11-16 双 MCP Server CVE**：`126816`（aws-pricing 路径穿越任意写，**工具被错误标记 read-only 致客户端自动批准**）/ `126681`（Timestream 不限制端点，prompt injection 泄漏 API token）→ 声明层零信任 + 输出/端点面。
3. ⭐ **官方 MCP Python SDK `CVE-2026-115563`（7.5）**：向不可信 auth 端点泄漏 OAuth 密钥；**code-review-mcp-server `CVE-2026-68934`（8.7/CWE-78）**：`folderPath` 拼进 `execSync` 跑 shell → 「升级官方 SDK ≠ 安全」。
4. ⭐ **IBM ContextForge `CVE-2026-110279`（8.1，修 1.1.1）**：特制 HTTP header 覆盖上游凭据，破坏身份隔离与审计 → 身份覆盖面。
5. 商业侧：**SnapLogic 11-17 发布 Discovery Hub**（MCP 中央注册+治理+可观测，客户含 AstraZeneca/Adobe/Verizon/Sony）；**企业 AI 控制面五原语**（scoped credentials / 每次调用运行时策略 / 单一治理注册表 / 可审计归因 / 动作级 RBAC）；**Schwab 受控门复盘**（机构自有 IdP、读写分 scope、带外确认、记动作不记聊天）；**Masttro 11-16 / Tochka Bank 11-16** 受监管金融 MCP 默认禁用+显式授权+严格只读+可撤销+人工签名。

## 3. 工程实测

```
cd examples/result-field-guard
javac -encoding UTF-8 McpResultFieldGuard.java
java -Dfile.encoding=UTF-8 McpResultFieldGuard

attack=27 control=12 boundary=4 TOTAL=43
incremental(legacy allowed but blocked)=16 / control false-positive=0
failures=0
SELF-TEST OK (pure JDK, zero dependency, all groups green)
```

- **27 攻击全拦 / 12 合法对照 0 误杀 / 4 边界断言**；JDK 17.0.8 实测。
- 对照组刻意包含：非敏感字段前缀搜索（50/100 次）、敏感字段**等值单次**查询、允许根目录内写文件、白名单端点外发、安全 `git status`。
- **「不得劣于旧基线」断言**：旧基线（信 `readOnlyHint` 或「无副作用即放行」）会放行的 16 条攻击，新守卫全部拦下；任一合法对照被误杀即整组失败。
- **审计脱敏断言**：明文 `supersecret` 永不出现在审计行；被拒调用不写 allow 审计。

> **兑现 V1.73 待办③**：延续「在任何一层都可能是边界」的方法论，把结果面做成第五个可运行 Gate 参考实现（与 `gate-orchestration` 的注册期/配置面/调用期链同构，本期新增**结果返回期**）。

## 6. ⚠️ 诚实边界

- 本框架**不受** REBUILD / AWS / IBM / Python SDK / code-review 等第三方 CVE 直接影响；`examples/` 是对其攻击范式的独立参考实现。
- 结果面守卫**仍在 `examples/` 层、未接入 21 个主模块**；敏感字段检测是字段名 token 归一化匹配非语义解析；盲注阈值为演示常量；IP 字面量一律拒绝是保守策略；shell 元字符是词法黑名单非解析器；`readOnlyHint` 是声明布尔值非密码学签名。
- REBUILD / AWS / SnapLogic / Masttro / Tochka 数据以官方稿为准；Schwab「受控门」为其架构复盘分析。
- 国家管网 4089 万 / 河北政采 48.9 万**未点名 MCP，不计入可投清单**；用友蓝皮书为买方口径非招标。
- 全部报价 / JD 薪资 / 预算为公开挂牌或预算上限**非成交价**；OpenAI×Upwork 为相关性分析非因果；Upwork Q3 数据为 11-12 披露（非近 3 天发生）。
- 本项目无企业主体 / 商业合同 / 中标 / 金融案例 / 等保测评；广发四份为预征集 ≠ 采购邀请，7 项资质全不满足只能联合体技术分包；Spring AI 2.0 **未执行升级**；`exportPrometheus()` 挂 actuator、`dataClassification` 差异化审批引擎、重定向逐跳 SNI 证书校验仍为跨期待办。
