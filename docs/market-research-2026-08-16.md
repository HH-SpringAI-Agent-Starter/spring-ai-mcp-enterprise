> 调研日期：2026-08-16 | 方式：web_search（最近一周窗口）+ 热点信源深度解读 | 关联：MCP Enterprise Server V1.5（网关友好标头）

## 一、本周最大热点：MCP 无状态化 RC 深度解读（AI 前线 8-16 发布）

The New Stack 深度长文《MCP Release Candidate Rewrite》被 AI 前线翻译首发（8-16 上午），核心信息：

- **MCP 迎来发布以来最大更新**：砍掉初始化握手、废除会话粘滞，每个请求独立携带上下文
- **网关友好标头（新基建）**：`Mcp-Method` / `Mcp-Name` 标头让**网关无需解析 JSON 请求体**即可按操作限流/授权——"网关/API 网关按操作进行速率限制或授权"成为平台团队刚需
- **缓存规范升级**：列表/读取结果必须携带 `ttlMs` + `cacheScope`（参考 HTTP Cache-Control），客户端可在指定间隔内保留目录
- **确定性排序**：服务端须按确定性顺序返回条目，提升提示词缓存命中率，大规模场景降低延迟与 Token 成本
- **迁移路径**：客户端先 `server/discover` 探测，遇到旧版服务器回退 `initialize`；10 周验证期 + Python/TS/Go/C# 测试版 SDK
- **生态动态**：MCP 于 2025-12 捐赠给 Linux Foundation 旗下 Agentic AI Foundation（AAIF），标准化进程加速

**对本项目的意义**：V1.5 已提前落地网关友好标头 + 传输验证 + ttlMs/cacheScope + 确定性排序，**与最终版规范同频**——这是"企业级 MCP 底座"最强的差异化卖点，也是本周博客引流的最佳选题。

## 四、风险与注意

- 新旧协议共存期"故障率可能更高"（AgentStatus 创始人 Román Moskalenko 原话）——**兼容双协议**（2026-07-28 + 2025-03-26）是卖点也是底线，本框架已支持
- 无状态化意味着"协议不再管理状态，但状态并未消失"——句柄/购物车/任务记录仍需存放，**企业级实现需要显式句柄模式支持**（V1.6 候选）
- 警惕营销文夸大薪资，实际价格带以 3-15 万（外包）/ 10-50 万（底座）为锚
