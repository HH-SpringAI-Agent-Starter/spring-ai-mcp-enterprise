## 八段式 → 九段式

注解（V1.69）→ 注册中心（V1.70）→ 只读声明（V1.71）→ 决策层（V1.72）→ 配置面（V1.73）→ 结果面（V1.74）→ 身份传播面（V1.75）→ 会话/传输绑定面（V1.76）→ **执行环境隔离面（V1.77）**。

前八段管「谁能动 / 怎么判 / 交出什么 / 收到谁的身份 / 从哪个会话哪个 Origin 进来」，第九段管「工具真正落到执行环境那一刻，沙箱 confinement 到底闭没闭合」——执行环境是最后落点：路径被穿越、命令被执行成 shell、env 被注入、会话被跨用户冒用，前面八段的授权判定全部失去意义。

## 六道闸 CP1–CP6

| 闸 | 控制点 | 对位风险 |
| --- | --- | --- |
| CP1 | 读写路径同等 confinement：拒绝对路径逃逸 / `..` 遍历 / symlink / 控制字符 | Gortex 62964 / yt-mcp 75612 |
| CP2 | 命令 allowlist + argv shell 元字符拒绝 + 解释器直执拒绝 + 非管理员写注册拒绝 | MCPHub 79748（9.9）|
| CP3 | env 源头白名单 + 危险键（`LD_PRELOAD` 等）拒绝 + 值中命令替换拒绝 | Hermes p22p |
| CP4 | 服务端独立定级：写动词不看 readOnlyHint、必须审批令牌；声明说谎单独拒绝 | DOMShell 75518 / Gortex 62964 |
| CP5 | 会话按 issuer + subject 绑定；共享 OAuth client 无真实 subject 拒绝；主体不一致拒绝 | Python SDK 52869（在野）|
| CP6 | append-only 脱敏审计：不记原始 env 值 / 凭据，只记规范化 op/path/subject | 审计泄露 / 不可抵赖 |

## 诚实边界（延续口径）

- **本框架不受** MCPHub / Hermes / Gortex / Python SDK 等第三方 CVE 直接影响；引用为设计依据。
- 新守卫**仍在 examples/ 层未接入 21 个主模块**；策略硬编码、符号链接集合模拟、单进程审计表均为演示约束，不得当生产组件。
- `CVE-2026-52869` 于 V1.76 会话面曾引用其兄弟洞 `115563`（客户端 OAuth 错投），本期为服务端 session_id 路由洞的独立复验；修复版本以官方公告 / GHSA 为准，升级到 1.27.2 仅修本洞、须 1.30.0 / 2.2.0 才连修 9 月洞。
- 广发四份为预征集 ≠ 采购邀请；本项目 7 项资质全不满足，只能联合体技术分包；无企业主体/合同/中标/金融案例/等保测评。
- 全部报价为公开挂牌价/估算非成交价；湖北工程学院 120 万智能体标未点名 MCP 不计入可投清单；Spring AI 2.0 未升级。
