# V0.17 Release Notes — Spring AI MCP Enterprise

> 版本: V0.17 | 状态: 开发版 | 日期: 2026-08-03
> 主题: **Streamable HTTP 传输层补齐 — 对齐 2026-07-28 规范新默认**

## 🎯 里程碑意义

V0.17 补齐了 2026-07-28 规范声明的 **Streamable HTTP 双通道**：
此前能力声明 `supportedTransports: [streamable-http, sse]` 但缺少 server→client 事件流端点，
本次补上 GET 流 + 通知广播，运输层完整度对齐规范。

## ✅ 新增内容

### 1. Streamable HTTP GET 事件流端点（mcp-server）

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/mcp/v2/stream` | GET | server→client 通知流（SSE），连接即发 endpoint 事件，15s 心跳保活 |
| `/api/mcp/v2/notify` | POST | 触发 `notifications/tools/list_changed` 广播，返回投递数 |
| `/api/mcp/v2/health` | GET | 增强：新增 `transport: streamable-http` + `connectedStreams` 指标 |
| `/api/mcp/v2` | GET | 能力声明新增 `transport.streamableHttp` 通道定位 |

### 2. 传输能力声明细化（mcp-core）

`SERVER_CAPABILITIES_V2026.transport` 新增 `streamableHttp` 子对象：

```json
{
  "stateless": true,
  "supportedTransports": ["streamable-http", "sse"],
  "streamableHttp": {
    "endpoint": "/api/mcp/v2",
    "stream": "/api/mcp/v2/stream",
    "message": "/api/mcp/v2/message",
    "notify": "/api/mcp/v2/notify"
  }
}
```

### 3. 示例与文档

- `examples/curl-examples.sh`：追加 Streamable HTTP 6 步示例（能力声明/健康/初始化/tools/list/tools/call/事件流/广播）
- `README.md` + `README.zh-CN.md`：营销话语从"SSE 流式调用"切换为"Streamable HTTP 无状态调用"（对齐 2026-07-28 规范与市场叙事）
- `docs/blog-streamable-http-2026-08-03.md`：掘金/CSDN 投稿稿
- `docs/market-research-2026-08-03.md`：晚间市场扫描
