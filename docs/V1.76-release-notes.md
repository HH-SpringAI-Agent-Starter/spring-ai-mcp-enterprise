## 七段式 → 八段式

注解（V1.69）→ 注册中心（V1.70）→ 只读声明（V1.71）→ 决策层（V1.72）→ 配置面（V1.73）→ 结果面（V1.74）→ 身份传播面（V1.75）→ **会话 / 传输绑定面（V1.76）**。

前七段管「谁能动 / 怎么判 / 交出什么 / 收到谁的身份」，第八段管「这条调用是从哪个会话、哪个 Origin、哪个 Host 进来的」——传输绑定是最后一道入口关：会话被冒用、Origin 被伪造、Host 被注入，前面七段的授权判定全部落在错误的入口上。

## 六道闸 CP1–CP6

| 闸 | 控制点 | 对位风险 |
| --- | --- | --- |
| CP5a | 未认证主体派发第一道门拒绝 | 130007 无 authorization 即派发 |
| CP1 | 会话服务端 HMAC 签发 + 绑定 principal+Origin，拒伪造/未注册/prototype-inherited | 131857 原型链继承 / 会话冒用 |
| CP2 | WS 升级/SSE 握手必带 Origin、白名单、与会话绑定一致 | 132121 跨站 WS 劫持 |
| CP3 | Host 按 RFC 9112/3986 逐字符校验，拒分隔符/问号/井号/@/控制字符 | 48710 BadHost URL 重解析绕过 |
| CP4 | OAuth 凭据声明 issuer 且等于预期授权服务器 | 115563 凭据错投 server 自选 AS |
| CP5 / CP6 | 默认只读 + append-only 脱敏审计（sessionId 打码） | 130007 read-only 默认关闭 / 审计泄露 |

## 诚实边界（延续口径）

- **本框架不受** Supergateway / k8s-mcp-server / Starlette / Python SDK 等第三方 CVE 直接影响；引用为设计依据。
- 新守卫**仍在 examples/ 层未接入 21 个主模块**；示例密钥硬编码、会话表进程内、Host/Origin 字面量校验均为演示约束，不得当生产组件。
- `CVE-2026-48710` 曾于 V1.64 蜜罐链出现，本期为其 Host 注入机制 + MCP discovery 端点放大的独立复验；修复版本以官方公告 / GHSA 为准。
- 广发四份为预征集 ≠ 采购邀请；本项目 7 项资质全不满足，只能联合体技术分包；无企业主体/合同/中标/金融案例/等保测评。
- 全部报价为公开挂牌价/估算非成交价；浙江工商大学 130 万智能体标未点名 MCP 不计入可投清单；Spring AI 2.0 未升级。
