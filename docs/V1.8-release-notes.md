# V1.8 Release Notes — Spring AI MCP Enterprise

> 版本：V1.8 | 日期：2026-08-20 | 状态：已完成

## 版本说明

V1.8 是 **「企业 M2M 凭证安全：OAuth2 Client Credentials + EMA（Enterprise-Managed Authorization）」** 的落地版本。基于 2026-08-20 最新市场调研，「统一鉴权/OAuth2/集中授权/最小权限短期凭证」是企业采用 MCP 时点名率最高的摩擦点（EMA 扩展已被 Anthropic/Microsoft/主流 SaaS 采用，MCP 已捐赠 Linux Foundation AAIF）。V1.8 补齐了从「长期共享 API Key」到「短期机器凭证」的安全升级，让框架真正达到企业生产就绪。

## 本期变更内容

### 1. 🔐 新增 `McpOAuth2Manager`（mcp-core）
- **OAuth2 `client_credentials` 授权**：企业 AI Agent / 系统间调用获取短时 access_token，替代长期共享 API Key
- **客户端注册**：`client_id/client_secret + roles + scopes`；secret 采用 **SHA-256 散列存储**（不落明文）
- **JWT 风格令牌**：HMAC-SHA256 签名，带 `iat/exp/scope/client_id` 声明，防篡改
- **scope 收敛**：只授予客户端已授权 scope，防止越权申请
- **令牌内省（RFC 7662）**：`introspect` 返回 active/scope/exp/client_id/roles
- **令牌吊销**：内存吊销清单，吊销后立即失效
- **EMA 外挂接口** `TokenIntrospector`：可无缝委托企业现有 IdP/OIDC 做**集中授权**（呼应 EMA 标准），也可切换回内部校验

### 2. 🌐 新增 OAuth2 REST 端点（mcp-server）
```
POST /oauth2/token        — client_credentials 授权，签发 access_token（x-www-form-urlencoded）
GET  /oauth2/introspect   — RFC 7662 令牌内省（网关/资源服务器校验）
POST /oauth2/clients      — 注册客户端（返回一次性明文 secret）
DELETE /oauth2/clients/{clientId} — 吊销客户端
GET  /oauth2/stats        — 活跃客户端数 / TTL / 是否 EMA 外挂
```

### 3. ⚙️ 配置（`mcp.enterprise.oauth2`）
```yaml
mcp:
  enterprise:
    oauth2:
      enabled: true
      signing-key: ${MCp_OAUTH2_SIGNING_KEY:change-me-in-production}
      token-ttl-seconds: 3600
```

## 集成方式

1. 注册客户端：`POST /oauth2/clients?clientId=agent-1&roles=user&scopes=tools:read tools:call`
2. 换取令牌：`POST /oauth2/token`（grant_type=client_credentials + client_id/secret）
3. 网关校验：将 access_token 作为 Bearer 传给 `/oauth2/introspect` 或直接调 `McpOAuth2Manager.validateToken`
4. 企业 IdP 接入：实现 `TokenIntrospector` 并 `setExternalIntrospector(...)`，即切换到 EMA 集中授权
