# V1.78 Release Notes（2026-11-24）

## 判词

**浏览器 / 出站响应面 + 本地绑定面也不是安全边界** —— 十段式收口第十段。

前九段（注解 → 注册中心 → 只读声明 → 决策层 → 配置面 → 结果面 → 身份传播面 → 会话/传输绑定面 → 执行环境隔离面）全部守请求端；V1.78 首次守**出站方向**：CORS 是跨域读取策略不是认证、loopback 是网络位置不是授权、session id 是传输句柄不是身份。出站响应头、监听地址、工具实参三处必须在服务端独立收口，默认 fail-closed。

## 本期证据（近 3 天，已回原文核实）

- `CVE-2026-34237` / `GHSA-hv2w-8mjj-jw22`（11-22，CVSS 6.1）：MCP **Java SDK** `mcp-core` SSE / Streamable HTTP 下发 `ACAO: *`，浏览器成中继读 SSE 首帧 session id 再跨域 POST；影响 `<1.0.0/<1.1.1/<0.18.3`，修 `1.0.1/1.1.1/0.18.3`。⚠️ 本项目核心依赖官方 SDK，须显式披露 + 部署后复查。
- `CVE-2026-112136`（8.8）/ `112137`（5.4）（11-23）：Siemens Mendix Studio Pro MCP Server 远程交互 + 浏览器 CSRF，OT 工程工作站任意 tool execution。
- `CVE-2026-134817`（7.1，CWE-88）（11-22/23）：mcp-server-kubernetes `<4.2.0` dash 前缀位置操作数被当 kubectl flag，修 `4.2.0`。
- 414 台公网 MCP server 审计 91.8% 无 OAuth（第三方数据，非本框架实测）。
- Launch Day Advisors 2026 全量定价：L1 只读 $100K–300K / L2 动作 $300K–700K / L3 agent-resident $1M+ / 运维 $5K–25K 月。

⚠️ 开发中对照组断言抓到并修正 3 处真问题：① CSRF 同源判定硬编码单一 host 误杀合法 admin 来源 → 改为对齐 CORS allowlist；② 审计断言请求被 CSRF 提前拦截不可达 → 用只读请求直达审计；③ C3 合法 Origin 改了但 Referer 夹具未对齐 → 修正夹具。**「只写顺风测试会选错方案」再验。**

## 诚实边界

- 本框架**不受**上述第三方 CVE 直接影响；但核心依赖官方 Java SDK，`34237` 须显式披露——升级只移除一处绕过，反向代理仍可能重加通配头。
- 参考守卫**仍在 examples/ 层未接入 21 主模块**；allowlist / token / 绑定地址硬编码、IP 字面量分类、session 绑定字符串标志为演示约束。
- 招聘薪资 / 报价为公开挂牌价非成交价；414 台审计 91.8% 为第三方数据；广发四份预征集≠采购邀请、7 项资质不满足只能联合体技术分包；中央民大/呼市/华安基金均未点名 MCP 不计入可投清单；Spring AI 2.0 未升级。
