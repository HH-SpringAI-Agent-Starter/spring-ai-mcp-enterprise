## 主题：持久化记忆 / 学习存储面也不是安全边界（十二段式收口第十二段）

前顺序：V1.69 注解 → V1.70 注册中心 → V1.71 只读声明 → V1.72 决策层 → V1.73 配置面 → V1.74 结果面 → V1.75 身份传播面 → V1.76 会话/传输绑定面 → V1.77 执行环境隔离面 → V1.78 浏览器/出站响应面 → V1.79 日志/遥测输出面 → **V1.80 持久化记忆/学习存储面**。

**判词**：持久化记忆 / 学习存储 / AgentDB pattern store / 向量库是「跨会话状态」，不是「已被批准的事实」。一次不可信工具写入就以「用户告诉我的」身份在未来每个会话被读回；readOnlyHint、来源自报、加密存储、打补丁都不构成边界。修复是写路径，不是过滤器；补丁 ≠ 清干净。
