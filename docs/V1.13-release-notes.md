# V1.13 发布说明：实例级多租户隔离（Instance-Level Multi-Tenancy）

> 版本：1.1.0（模块能力增强）| 日期：2026-08-29 | 前置：V1.11 Row（08-26）→ V1.12 Schema（08-27）→ V1.13 Instance（08-29）
> 设计文档：[multi-tenant-instance-research.md](./multi-tenant-instance-research.md)

## 一、本版本交付

V1.13 将多租户隔离从「共享数据库」推进到「物理级隔离」——**每个租户拥有独立的 DataSource 与独立连接池**（可指向独立数据库/实例），支撑金融、政务、医疗等数据驻留合规场景，也就是外包报价单上「企业多租户 $40K-80K」档的核心可演示能力。

### 新增代码（mcp-tenant 模块，`com.mcp.enterprise.tenant.instance` 包）

| 类 | 职责 |
|---|---|
| `TenantInstanceRegistry`（接口） | 租户 → DataSource 注册表：get / register / unregister / tenants / close；未注册租户 fail-closed 拒绝 |
| `DefaultTenantInstanceRegistry` | 并发安全实现（ConcurrentHashMap）；unregister 强制关闭连接池；重复注册自动关闭旧池（防泄漏）；close 释放全部池 |
| `TenantInstanceDataSource` | 路由 DataSource：每次 getConnection 从 TenantContext 解析租户 → 经注册表路由到该租户专属池；无租户/未注册一律抛 `TenantNotResolvedException` |
| `TenantInstanceProvisioner` | 按租户配置构建 HikariCP 池（配额/超时/生命周期）；`${ENV_VAR}` 密码占位符解析（系统属性优先，其次环境变量）；可选 initialize-DDL 每个池创建时执行一次 |
| `McpTenantInstanceAutoConfiguration` | 实例模式自动装配：静态租户池预置 + 上下文关闭时释放全部池（destroyMethod=close） |
| `TenantModeGuard` | 三模式语义校验 fail-fast：`mode=instance` 但 `instance.enabled=false` 时启动即失败，杜绝「静默无隔离」 |

### 配置方式

```yaml
mcp:
  tenant:
    mode: instance            # row | schema | instance
    instance:
      initialize-ddl: "CREATE TABLE IF NOT EXISTS app_data(id BIGINT AUTO_INCREMENT PRIMARY KEY, payload VARCHAR(500));"
      tenants:                # 静态预置，管理 API 可在运行时叠加
        acme-corp:
          url: jdbc:mysql://db-acme:3306/mcp
          username: acme_app
          password: ${ACME_DB_PASSWORD}   # 支持 ${ENV} 占位，密钥不进 git
          pool:
            maximum-pool-size: 10
            minimum-idle: 2
            connection-timeout-ms: 30000
            max-lifetime-ms: 1800000
        globex:
          url: jdbc:mysql://db-globex:3306/mcp
          username: globex_app
          password: ${GLOBEX_DB_PASSWORD}
          pool:
            maximum-pool-size: 5
```

## 二、三档隔离能力对照（产品故事线完整）

| 维度 | Row（V1.11） | Schema（V1.12） | **Instance（V1.13）** |
|---|---|---|---|
| 隔离边界 | 业务 SQL 行级（tenant_id 列） | 数据库 Schema | **独立 DataSource + 连接池 + 独立库/实例** |
| 故障域 | 无（共享表） | Schema 级（同库） | **物理级（库/实例）** |
| 资源配额 | 不可控 | 库内可调 | **每租户独立连接池/容量/限流** |
| 合规强度 | 中 | 高 | **最高（数据驻留/监管隔离）** |
| 业务代码改动 | 零（换 JdbcTemplate） | 零（换 DataSource） | **零（换 DataSource，X-Tenant-Id 链路不变）** |
