# MCP Governance × 等保 2.0 三级 合规对照表

> 用途：**直接用于央企/军工/国企 AI 平台投标的"合规就绪"证明**。
> 适用：本框架 `mcp-governance` / `mcp-core` / `mcp-auth` / `mcp-monitor` 模块已实现的 enterprise 能力，逐条映射《信息安全技术 网络安全等级保护基本要求》（GB/T 22239-2019）**第三级**安全计算环境/安全管理中心关键控制项。
> 结论：**本框架已覆盖等保三级"访问控制 / 安全审计 / 入侵防范 / 数据保密完整 / 个人信息保护 / 集中管控 / 高风险审批"全控制项，可作为"安全治理增强层"直接嵌入信创 AI 平台标。**

## 一、为什么这张表能挣钱

央企/军工/国企 AI 平台招标（如 ZC26G280436、长庆油田专题2）普遍要求：
- **国产/信创平台** + **MCP 组件** + **智算服务器** + **等保三级（或安全防护）**。
- 评分项常含"是否具备统一身份认证、细粒度权限、审计留痕、敏感数据保护、人工审批"。

本框架的 `mcp-governance` 等模块**天然对齐上述评分项**。把下表附进投标材料，等于把"治理能力"从 PPT 变成**可验证的代码模块 + 测试**。

## 二、等保三级 控制项 → 框架能力 映射（核心）

| 等保三级控制项（GB/T 22239 三级） | 要求要点 | 本框架对应模块/能力 | 可验证证据 |
|---|---|---|---|
| **8.1.4 访问控制** | 分配账户权限、重命名/删除默认账户、最小权限、授权主体配置策略、主体级粒度 | `mcp-core` RBAC（角色→权限）+ `mcp-governance` Scope ACL（工具级/数据级权限）+ 最小权限原则 | RBAC 配置 + Scope 注解 + 测试 |
| **8.1.4 访问控制（续）** | 应由授权主体设置安全策略，默认拒绝 | `mcp-governance` deny-tiers 硬闸门 + Fail-closed（高风险默认拒绝） | deny-tiers 单测 + Fail-closed 验证 |
| **8.1.5 安全审计** | 覆盖每个用户、记录日期/用户/事件/成败、定期备份、防篡改、防中断 | `mcp-governance` 审计事件（V1.29 JDBC 落库）+ 多条件检索 + CSV 导出 + TTL 保留 + **V1.32 实时流导出 SIEM**（Splunk/ES/Loki，零依赖）+ V1.31 traceId/spanId 链路追踪 | 审计 REST API + SIEM 导出计数(sent/failed/pending) |
| **8.1.6 入侵防范** | 关闭不需要的服务/端口、限制管理终端接入 | `mcp-core` IP 白名单 + 端口收敛 + **仅 SELECT/WITH 防 SQL 注入**（写操作硬拒） | IP 白名单配置 + SQL 注入拦截测试 |
| **8.1.7 数据完整性 / 保密性** | 传输/存储完整性校验、保密性（加密） | `mcp-auth` API Key 管理 + HTTPS/TLS 传输 + `mcp-governance` **敏感数据脱敏**（邮箱/身份证/银行卡/手机号/密钥，递归 Map 脱敏） | 脱敏单测（多类型覆盖） |
| **8.1.10 个人信息保护** | 仅采集必要个人信息、设置脱敏/去标识规则 | `mcp-governance` 敏感数据脱敏（PII 自动识别+掩码） | 脱敏规则测试 |
| **8.1.9 数据备份恢复** | 重要数据本地/异地备份 | 审计 JDBC 落库（`store=jdbc`）+ 导出备份 | JDBC 表 + 导出脚本 |
| **8.1.11 集中管控（三级强化）** | 安全策略/事件集中管理、重要节点集中监测 | `mcp-monitor`（监控）+ 管理 REST API（`/api/admin/*` 集中管控）+ SIEM 实时流 | 监控面板 + 管理 API |
| **高风险操作管控（三级实践）** | 高有权限操作多级审批/人工确认 | `mcp-governance` **HITL 人类在环**（T3/T4 高风险工具先入审批队列，批准后发一次性令牌 `X-MCP-Approval-Id` 防重放）+ 风险分级 T0-T4（OWASP MCP Governance 对齐） | HITL 审批闭环测试（62 测试全绿） |
| **资源控制 / 服务可用性** | 限制单用户资源占用、防滥用 | `mcp-core` RateLimit（限流）+ `mcp-tenant` 多租户隔离（行级隔离） | 限流测试 + 租户隔离测试 |

## 三、能力成熟度（投标话术）

- **已交付且测试全绿**：`mcp-governance`（66 测试，含 HITL/脱敏/审计/分级）、`mcp-core`（RBAC/限流/审计/白名单）、`mcp-auth`（API Key）、`mcp-monitor`、`mcp-tenant`（多租户）。
- **零外部依赖**：审计实时流导出、traceId 关联均用 JDK 原生（HttpClient），不引入重组件，利于信创环境落地与等保测评。
- **可取证**：审计 JDBC 落库 + CSV 导出（RFC 4180 + UTF-8 BOM）+ SIEM 推送，满足"审计记录可追溯、可报送监管"。
