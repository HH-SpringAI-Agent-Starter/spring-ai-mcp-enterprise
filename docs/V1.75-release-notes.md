## 六段式 → 七段式

注解（V1.69）→ 注册中心（V1.70）→ 只读声明（V1.71）→ 决策层（V1.72）→ 配置面（V1.73）→ 结果面（V1.74）→ **身份传播面（V1.75）**。

前六段管「谁能动 / 怎么判 / 交出什么」，第七段管「被调用方真正收到谁的身份」——身份令牌在网关→上游转发途中被错误路由、覆盖或重放，则前六段授权判定全部落空。

## 六道闸 CP1–CP6

| 闸 | 控制点 | 对位风险 |
| --- | --- | --- |
| CP1 | 声明 block 字段被请求 → 拦截（fail-closed） | 110278 配置被忽略 |
| CP2 | 只转发按需 + allowlist 字段，其余剥离 | 过度身份暴露 |
| CP3 | 拒绝静态签名；5 分钟窗口；nonce 防重放；HMAC | 110278 静态重放 |
| CP4 | 拒绝覆盖上游凭据的 header | 110279 header 覆盖 |
| CP5 | 身份 tenant = server tenant | 跨租户泄露 |
| CP6 | append-only 脱敏审计（email 打码 / groups 计数） | 审计成泄露源 |
