## 治理护城河再验证（最强卖点）
本月所有重大 CVE 的缓解控制，本框架**默认生效**：
- CVE-2026-59822（CISA KEV，无效 bearer token）→ `mcp-auth` Bearer 强制校验（V1.9 RFC 6750）+ jti 防碰撞 + 吊销端点。
- CVE-2026-14540（CVSS 8.0 SSRF）→ `tool-http` SSRF 防护（V1.1）+ 治理出站 allowlist。
- CVE-2026-19516（会话伪造）→ RBAC + Scope→Tool ACL（V1.19）+ Signed Agent Card（V1.18）。
- 无审计/无审批 → HITL（V1.26）+ JDBC 审计落库（V1.29）+ SIEM 实时流导出（V1.32）+ 等保三级对照表。
