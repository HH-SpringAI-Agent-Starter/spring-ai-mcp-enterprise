## 五、用户「Java + Spring + AI」在该赛道的 8 条卖点

1. **审批链可现场证伪**：确认令牌自批、scope 提权、只读委托链三类攻击可现场复现并被拦；31 断言全绿、旧基线漏 15/20。
2. **不靠模型自证**：`readOnlyHint`、claimed scope、审批弹窗一律只进审计不进允许分支，对齐 arXiv 模型外确定性监控实证。
3. **Spring AI Alibaba 兼容层**：治理核心基于官方 SDK、Alibaba 作为可选适配层，不被单一平台绑定；Nacos/Higress 越强，执行门空隙越清晰。

5. **私有化合规工件**：RBAC/RateLimit/审计/API Key/注册中心/REST API 已成型，适合金融与工业软件私有部署。
6. **十二段式攻击面清单**：注解→注册中心→只读→决策→配置→结果→身份→会话→执行环境→出站→日志→记忆→**审批链**，46→48 类，可按买方行业裁剪成 POC 脚本。
