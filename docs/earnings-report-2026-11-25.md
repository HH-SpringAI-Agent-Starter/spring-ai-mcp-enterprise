## 六、Java + Spring + AI 在 MCP 赛道的 8 条卖点

1. **可观测性出口 = 数据出口**：日志行 / 指标标签 / 诊断响应必须在出口按内容独立脱敏——`redactSensitive=true` 是声明不是执行（135614 实证）。
2. **打补丁 ≠ 清干净**：AWS 要求升 0.1.36 **且轮换凭据**；本项目付"存量全量复验"制度化工件（延续 V1.70 判词）。
3. **IP 分类完整性**：IPv6 site-local `fec0::/10` 漏判（134492）说明出口 allowlist 必须做全地址族词法分类，不能只看 IPv4。
4. **买方四问直接对位**：代表谁（身份传播面）/ 可执行什么（注解+注册面）/ 何时转人工（确定性执行门）/ 能否追溯（本期 append-only 脱敏审计）。
5. **十一期十一护栏、每期可现场跑**：`javac` + `main()` 自检全绿、含对照组（合法 0 误杀），售前可演示而非 PPT。
6. **Java/Spring 原生 + Spring AI Alibaba 可选兼容层**：适配工业软件（凯世通 SECS/GEM→MCP）与金融合规（Airwallex）JD 的逐字技术栈。
7. **四语言 Client SDK + docker-compose + CI 已在位**：非 Demo 级骨架，降低买方"能不能落地"疑虑。
8. **RICP 清单验收可进标书**：RFP 攻击面 42→44 类，每类给控制点、真实文件与现场验收方式；⚠️ 资质不足只能联合体技术分包，禁虚构案例。
