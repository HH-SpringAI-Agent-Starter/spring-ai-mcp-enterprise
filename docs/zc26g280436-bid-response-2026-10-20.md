## 第 4 章 安全事件简报（合规加分 / 审计交付物）

> 完整 10 起事件 → [`mcp-security-incident-brief-2026-10.md`](mcp-security-incident-brief-2026-10.md)
- LiteLLM MCP 端点任意无效 token（CVE-2026-59822，**CISA KEV**）→ 本框架 `mcp-auth` Bearer 强制校验 + jti 防碰撞 + 吊销端点
- Grafana MCP 会话伪造 SSRF（CVE-2026-19516）→ `mcp-governance` SSRF 防护
- 官方 Java/Kotlin SDK 无界缓冲 DoS（CVE-2026-108395 / 108714）→ `mcp-core` 限流 + 资源隔离
- **SAS 权威背书**："MCP is not a security governance or compliance framework" → 本框架补上 SAS 说的"组织要自己设计的保险丝盒"
