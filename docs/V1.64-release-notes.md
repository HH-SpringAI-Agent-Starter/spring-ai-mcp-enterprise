## 🔧 工程增量说明（本次真实新增代码）

`examples/governance-hardening/` 是针对**本周公开实证攻击面**的可参考实现，覆盖：

1. **4 MiB 请求体上限**（声明值 + 流式双限）→ `CVE-2026-108395` 官方 Java SDK `mcp-core` 无界请求体 DoS
2. **鉴权 fail-closed**（signature / aud / iss / exp / scope 全校验）→ `CVE-2026-59822` 一个字符 token、`CVE-2026-123272/123271` OAuth resource confusion
3. **同源 + 禁跟随跨源 307/308** → `CVE-2026-48710` host-header 绕过、`CVE-2026-111769` 重定向泄漏 refresh_token
4. **会话指纹 = 租户 + subject + clientId** → `CVE-2026-121419` 按 access method 名导致会话劫持
5. **工具默认 disabled + 配置字段校验 + 测试端点沙箱** → `CVE-2026-42271` 伪造配置启动矿机（对标 Uber 800+ servers 生产实践）
6. **工具级 ACL 复用主 API 对象授权 + 写操作 HITL** → `CVE-2026-121458` MCP 侧门越权、Agiloft 人工确认
7. **进程行为可观测**（shell / 子进程 / 出站 / 凭据访问）→ Wiz 内存抠 master key、`.claude/unicorn` 伪装矿机

> ⚠️ **构建安全**：示例位于 `examples/` 下，**不在 `pom.xml` 的 `<modules>` 中，不参与 Maven reactor 与 CI 构建**，仅依赖项目已有的 `spring-boot-starter-web` + `jakarta.servlet-api`。集成方式见该目录 README。
