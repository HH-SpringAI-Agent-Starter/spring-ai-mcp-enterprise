## 二、为什么（市场信号）

1. **Uber MCP Gateway 生产实证（最强新叙事）**：800+ servers / 5,000+ tools；**默认全部 disabled、归属团队审核后启用**（与运行时权限检查分离）；按 caller（human / service account / autonomous agent）套 per-server charter policy + per-tool override；授权与 PII 脱敏在请求路径执行；Omni MCP 四元工具增量发现 + Response Projection；结论"Gateway 既是协议路由器也是产品管理平台"。→ 本框架 `mcp-registry`+`mcp-governance`+`mcp-tenant` 首次拿到**超大厂生产级架构对标**，可进标书"业界对标"章节。
2. **CVE-2026-108395 命中官方 Java SDK `mcp-core`**：全 SDK 级无界请求体 DoS，无需认证/交互、一个超长请求打挂进程；各家统一修为 **4 MiB 上限**；TS SDK 月下载 2.57 亿 / Py 2.35 亿；Red Hat Important 评估 44 产品发 VEX、Debian grave。**最锋利的一点**：两条 SDK CVE 未进 GitHub Advisory Database → `pip-audit`/`osv-scanner`/Dependabot 全部漏报；截至 11-03 官方 best-practices **仍无 body 大小指引**，NSA/CISA 信息表也无具体控制项。→ 话术升级为「官方修实现层的洞；规范空白与逐工具授权/防篡改审计只能由治理增强层补」。
3. **同日两款「受治理 MCP」上线（11-05）**：ISI Markets（4,000 万+ 新闻 / 年 50 万研报 / 200+ 经济体，标题即 Governed access，按订阅内容·数据 entitlements·AI 使用权授权、来源引用）+ Agiloft（CLM，Claude 首个 beta 客户端，保留既有 permissions/controls，Bulk Update 写操作**必须显式人工确认**+预览+报告）→ 高敏数据/合同业务上 MCP，**治理是产品定义而非附加项**。
4. **Upwork Now 公测（11-02）平台侧财报级证据**：MCP server 上线以来周活 **×20**；Q3 **AI 技能人才 GSV 同比 +55% 至 $112M**（总 GSV −10% 至 $914.1M、每活跃客户 +8% 至 $5,418）；典型雇佣 <30 分钟、最快 <10 分钟、57% 客户希望 1 天内雇到 → MCP = 真交易入口，AI 技能逆势涨价。
5. **差异化再夯实**：11 月企业网关横评 Bifrost(Go)/Docker(MIT)/Microsoft/AWS AgentCore/Kong **清一色非 Java 栈**，且 RBAC/SSO/HMAC 审计/guardrails 普遍只在 Enterprise tier（Bifrost 明示 Enterprise 是 OSS 严格超集）→ **治理 = 行业付费墙，本框架开源即给**；Bifrost virtual keys deny-by-default 与 Uber 默认禁用撞出同一设计共识。
6. **需求转向「存量 Java 平台 MCP 化」**：金山办公（"推进现有平台能力向 MCP Server 的标准化封装"）+ 美团（"MCP Server 的接入与管理、工具沙箱与权限管控"）+ 建发 50–80k（RAG/Skill/**MCP 开发** + Java/Spring Boot/Cloud）+ 上海整车厂 Harness 40–70k·15薪（**MCP 工具注册**/A2A 标准化/配额限流/隐私权限边界）→ 与 11-03 Digital Dhara "connect various nodes of J2EE" 同构，改造存量 Java 资产成主线。
7. **规范级合规背书**：AI Agent Governance 三层框架（供应链验证 / 运行时执行 / 防篡改审计）+ 明确论证 IAM/DLP/API 网关/代码扫描都不够 + NIST AI RMF / EU AI Act / CMMC L2/3 / HIPAA / SR 11-7 / 21 CFR Part 11；中文治理指南七维框架 + 9 条基线（写操作单独申请、身份透传、日志≥180 天、统一网关禁直连、高危动作人工确认、配置走评审）→ 已抽成 earnings-report 第九节对照表。
8. **国内预算接力**：重庆 AI 大单 **3.4412 亿**（11-03 中标候选，招标范围含"智能体及应用场景建设"）+ 中央民大 **3712 万**（11-25 截，含"民族语言多模态大模型智能体"）+ 上外 **589.28 万**（11-04 中标）。
