## Honest scope
- Guard 仍在 `examples/` 层，**未接入 21 个主 reactor 模块**；`ATTACHED` 是进程内 Map、会话/令牌绑定是字符串标志，**非分布式会话存储 / 非密码学签名 / 非真实传输层实现**。
