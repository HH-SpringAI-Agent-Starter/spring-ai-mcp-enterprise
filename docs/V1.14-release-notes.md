# V1.14 发布说明 — 租户生命周期管理 REST API

> 发布日期：2026-08-30
> 核心主题：**实例级多租户从「启动配置」走向「运行时运营」** —— 无需重启即可开通、替换、挂起、恢复、销毁租户独立实例池。

---

## 一、为什么做 V1.14

V1.13 落地了实例级多租户（每租户独立 DataSource + HikariCP 连接池），但租户的「增删改」只能通过修改 `mcp.tenant.instance.tenants` 配置并重启完成。对企业运营而言这不可接受：

- **SaaS 开单即用**：新客户签约后 2 分钟开通，而不是等发版窗口；
- **欠费/违规即停**：挂起租户必须立刻 fail-closed，不能等重启；
- **到期即清**：销毁租户需释放连接池，杜绝资源泄漏。

V1.14 用一组管理 REST API 把这些能力暴露出来，**并且与静态配置走同一条数据通道**（同一个 `TenantInstanceRegistry`），保证「启动配置的租户」和「运行时开通的租户」在数据访问层完全等价。

## 二、新增内容

### 1. 租户生命周期管理核心（mcp-tenant）

| 类 | 职责 |
|---|---|
| `TenantLifecycleManager` | 运行时租户生命周期编排：provision / suspend / resume / remove / list / get；按租户同步 + ConcurrentHashMap，并发管理不泄漏连接池 |
| `TenantLifecycleState` | 租户状态机：`ACTIVE`（池在册可用）/ `SUSPENDED`（池已释放、fail-closed 拒绝访问、spec 保留可秒级恢复） |
| `TenantLifecycleInfo` | 租户运行时快照（状态 + JDBC URL + 池配额 + 时间线），密码永不外泄 |

安全性继承 V1.13 全链路：`${ENV}` 密钥占位解析、initialize-DDL 幂等执行、挂起即 `registry.unregister`（fail-closed 拒绝）、销毁强制关池。

### 2. 管理 REST API（mcp-server）

统一挂在 `/api/admin/tenants` 下（与既有 admin 端点同一受保护域，需管理员认证/网络策略）：

| 方法 | 路径 | 语义 |
|---|---|---|
| `GET` | `/api/admin/tenants` | 列出全部托管租户（含挂起态） |
| `GET` | `/api/admin/tenants/{id}` | 租户详情 |
| `POST` | `/api/admin/tenants` | **开通/替换**租户（body 传 JDBC spec + 池配额） |
| `POST` | `/api/admin/tenants/{id}/suspend` | **挂起**（释放池，fail-closed） |
| `POST` | `/api/admin/tenants/{id}/resume` | **恢复**（用保留 spec 重新建池） |
| `DELETE` | `/api/admin/tenants/{id}` | **销毁**（释放池 + 遗忘租户） |

错误语义：未知租户 → `404`；非法载荷（空租户 id / 缺 url）→ `400`；状态冲突（挂起未托管租户）→ `409`。

### 3. 示例请求

```bash
# 开通租户 acme（独立 MySQL 实例 + 池配额）
curl -X POST http://localhost:8080/api/admin/tenants \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "tenantId": "acme-corp",
    "url": "jdbc:mysql://db-acme:3306/mcp",
    "username": "acme_app",
    "password": "${ACME_DB_PASSWORD}",
    "pool": { "maximumPoolSize": 10, "minimumIdle": 2 }
  }'

# 挂起租户（立即 fail-closed）
curl -X POST http://localhost:8080/api/admin/tenants/acme-corp/suspend \
  -H "Authorization: Bearer <admin-token>"

# 恢复租户（用保留 spec 重建池，无需重传凭据）
curl -X POST http://localhost:8080/api/admin/tenants/acme-corp/resume \
  -H "Authorization: Bearer <admin-token>"

# 销毁租户（释放连接池）
curl -X DELETE http://localhost:8080/api/admin/tenants/acme-corp \
  -H "Authorization: Bearer <admin-token>"
```
