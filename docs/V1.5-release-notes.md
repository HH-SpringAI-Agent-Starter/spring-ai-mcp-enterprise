## 版本说明

V1.5 是 **2026-07-28 最终版规范「网关友好」特性的完整落地版本**。8 月 16 日 AI 前线/The New Stack 发布 MCP 无状态化 RC 深度解读，本版本提前同频实现其核心增量特性。

## 本轮变更内容

### 1. 🚦 网关友好标头（Gateway-Friendly Headers）✅
- **新增**：`Mcp-Method` / `Mcp-Name` HTTP 标头支持
- **核心价值**：网关/API 网关无需解析 JSON 请求体，仅凭标头即可按操作进行速率限制或授权
- **实现**：`McpStatelessEndpoint.validateGatewayHeaders()` — 传输验证规则，拒绝任何与正文不符的标头（防止标头掩盖真实调用）
- **路由元数据**：`buildGatewayRoute()` 静态方法，为网关中间件提供 method/operationType/name 分类（tool/resource/prompt/task/protocol）

### 2. 🗂️ ttlMs + cacheScope 缓存控制 ✅
- **新增**：`tools/list` 响应携带 `caching` 对象（`ttlMs` 新鲜度提示 + `cacheScope` 缓存作用域 + `etag`）
- **语义**：参考 HTTP Cache-Control；客户端可在指定间隔内保留目录，无需重复拉取
- **兼容**：保留 `_etag`/`_cachedAt` 旧字段供存量客户端读取

### 3. 🔤 确定性排序 ✅
- **新增**：`tools/list` 按工具 name 字典序返回
- **价值**：提升提示词缓存命中率；大规模场景降低延迟与 Token 成本（2026-07-28 规范要求）

### 4. 📡 能力声明升级 ✅
- `SERVER_CAPABILITIES_V2026` 新增 `gateway` 能力块（标头名 + transportValidation 声明）
- `caching` 能力块新增 `ttlMs` / `cacheScope` / `deterministicOrder`

### 5. ✅ 单元测试
- `McpStatelessEndpointTest` 新增 **8 项**（确定性排序、ttlMs/cacheScope、网关标头匹配/拒绝 ×3、缺失标头放行、路由元数据、能力声明）
