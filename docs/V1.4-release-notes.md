## 本轮变更内容

### 1. 📅 合规日历工具 finance_compliance ✅
- **新增**：`FinanceComplianceExecutor`（工具名 `finance_compliance`，分类 finance，权限 admin,user）
- **能力**：
  - `calendar`：生成指定年月（如 2026-08）的 A 股财报披露窗口合规日历（年报预告/业绩快报/年报/一季报/中报/三季报等 9 类节点，按月份过滤返回）
  - `deadline`：查询报告期披露截止日（年报 4/30、一季报 4/30、中报 8/31、三季报 10/31），返回剩余天数与是否逾期
- **面向场景**：合规日历助手、投研 Agent 的披露窗口提醒、监管节点清单

### 2. 🎯 风险评分工具 finance_risk ✅
- **新增**：`FinanceRiskExecutor`（工具名 `finance_risk`，分类 finance，权限 admin,user）
- **能力**：
  - `score`：五维加权综合风险评分（0-100）——偿债 30% / 流动性 20% / 盈利 20% / 成长 15% / 现金流 15%，输出风险等级（低/中低/中高/高）+ 分维度得分
  - `diagnose`：单维度快速诊断（debt/liquidity/profit/growth/cashflow），返回风险分 + 可读建议
- **面向场景**：信贷审批助手、投顾风控、尽调分析 Agent

### 3. ✅ 单元测试
