# V1.1.0 Release Notes — Spring AI MCP Enterprise

> 版本：V1.1.0 | 日期：2026-08-09 | 状态：发布

## 版本说明

V1.1.0 是 **V1.1 功能集（tool-http + OAuth2 client-credentials）的正式版本号对齐**。
此前 V1.1 功能已发布（tag v1.1）但 Maven 坐标仍停留在 1.0.0，本次将全部模块统一升版至 1.1.0。

## 变更内容

### 1. Maven 版本统一对齐 ✅

- 根 pom 及全部 13 个子模块 pom：`1.0.0 → 1.1.0`
- 覆盖模块：mcp-core / mcp-spring-boot-starter / mcp-server / mcp-auth / mcp-monitor / mcp-tools(7个) / mcp-integrations/mcp-alibaba / mcp-examples/mcp-client-spring-ai
- `mvn clean install -Pfull -DskipTests` 构建验证通过（含 Alibaba 集成模块）

### 2. 文档版本引用修复 ✅

| 文件 | 修复内容 |
|------|---------|
| docs/alibaba-integration-guide.md | Maven 依赖 `0.0.2-SNAPSHOT` → `1.1.0`（原版本号不存在，用户照做会拉取失败） |
| docs/blog-java-mcp-enterprise.md | `0.0.2-SNAPSHOT` → `1.1.0` |
| docs/blog-java-stateless-mcp-2026-08.md | `<version>1.0.0</version>` → `1.1.0` |

### 3. Docker Compose 版本标签修复 ✅

- docker-compose.yml：`mcp.enterprise/version=0.0.2` → `1.1.0`

### 4. 市场情报新增 ✅

- docs/market-research-2026-08-09.md：MCP 招聘/招投标/需求雷达（近 7 天）

## 构建验证

```
mvn clean install -Pfull -DskipTests -B -q  →  BUILD SUCCESS
产物：mcp-server-1.1.0.jar / mcp-alibaba-1.1.0.jar 等全部 1.1.0
```
