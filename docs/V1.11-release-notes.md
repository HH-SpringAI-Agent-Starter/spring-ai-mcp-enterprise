# V1.11 发布说明 — 多租户 Row-level 隔离（mcp-tenant）

> 发布日期：2026-08-26 | 版本：1.1.0（模块新增，非破坏性）

## 一、为什么做多租户

1. **市场硬信号**：MCP 岗位已把「multi-tenant isolation」写进 JD——
   - hirify.global Senior AI Engineer (MCP) $200-240K（旧金山）：明确要求 *OAuth/RBAC and multi-tenant isolation*、per-API-key usage tracking、rate limiting；
   - 行业分级（mejba 2026 课程）：*"Design multi-tenant MCP platforms"* 是 Tier-3 Senior MCP Architect 的定位分水岭；
   - 国内平台岗溢价：诺亚控股「MCP 平台开发高级工程师」40-60K/月 招 5 人（上海）。
2. **商业化解锁**：多租户 = 一个部署服务 N 个企业客户 = 企业平台 $25-60K/单档位（见 08-25 预研报告）。V1.11 是 V1.12 Schema 隔离、V1.13 实例隔离的第一步，也是投标/报价单上的硬能力。
3. **安全义务**：企业级 MCP Server 的审计与权限边界（RBAC）必须在数据层有兜底——Row-level 隔离保证「工具写错 SQL 也不跨租户」。

## 二、新增模块 `mcp-tenant`

| 组件 | 职责 |
|------|------|
| `TenantContext` | ThreadLocal + InheritableThreadLocal（异步线程自动继承）+ SLF4J MDC 标签（`mcp.tenantId`）+ `withTenant()` 作用域助手，异常时自动清理 |
| `TenantAwareJdbcTemplate` | 继承 `JdbcTemplate`，在 `applyStatementSettings(Statement)`（Spring JDBC 6.x 所有语句的统一执行前钩子）做 fail-closed 守卫 |
| `McpTenantFilter` | Servlet 过滤器，从 `X-Tenant-Id` 请求头解析租户并绑定上下文，请求结束强制清理 |
| `McpTenantProperties` | `mcp.tenant.*`：enabled / header-name / fail-closed / default-tenant |
| `McpTenantAutoConfiguration` | 自动注册过滤器 + 条件化包装容器中的 `JdbcTemplate` bean（@ConditionalOnBean） |

### Fail-closed 语义（安全默认）

- `mcp.tenant.fail-closed=true`（默认）：未解析到租户的 JDBC 操作直接抛 `TenantNotResolvedException`，防止跨租户写入/越权读取；
- `fail-closed=false + default-tenant`：混合模式，存量单租户服务平滑迁移；
- `mcp.tenant.enabled=false`：完全关闭（默认不迁移场景零影响）。

### 技术要点

- 拦截点选择：Spring JDBC 6.x 中 `execute(PreparedStatementCreator, PreparedStatementCallback)` 等公共重载**不在** `update()/query()` 的内部调用链上（内部直连 private 3 参 `execute`），因此改用 `applyStatementSettings(Statement)`——所有 Statement/PreparedStatement/CallableStatement（含 `execute(String)` DDL 路径）执行前必经此钩子。已用 H2 实测验证。
- 15 个单元测试全绿（TenantContext 9 + TenantAwareJdbcTemplate 6）：fail-closed 写入/查询拒绝、租户数据隔离、withTenant 清理、默认租户兜底、禁用模式兼容。

## 三、使用方式

```bash
# mcp-server 已内置依赖；启用示例 profile（或合并进 application.yml）
java -jar mcp-server/target/mcp-server-1.1.0.jar --spring.profiles.active=tenant
```

```bash
# 调用时带上租户头
curl -H "Authorization: Bearer $TOKEN" -H "X-Tenant-Id: acme-corp" \
  http://localhost:8080/mcp/stateless
```

业务 SQL 显式带租户列：

```java
String tenantId = TenantContext.currentTenantOrThrow();
tenantAwareJdbcTemplate.update(
    "INSERT INTO app_data(tenant_id, payload) VALUES (?, ?)", tenantId, payload);
```
