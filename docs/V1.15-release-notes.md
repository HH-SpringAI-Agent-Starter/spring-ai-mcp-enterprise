# V1.15 发布说明 — MCP + A2A 双协议网关（mcp-a2a）

> 发布日期：2026-08-31
> 核心主题：**一个网关，同时讲 MCP 和 A2A 两种语言** —— 把工具注册中心的 MCP 工具自动派生为 A2A Agent Card/Skill，任意 A2A 编排器可直接调用企业工具。
> 版本基线：V1.14（租户生命周期管理）→ V1.15

---

## 一、为什么做 V1.15

**市场信号（连续多期雷达验证）**：

1. **2026-08-20 A2A 正式并入 Linux Foundation AAIF**，与 MCP 同框架治理（AWS/Anthropic/Google/Microsoft/OpenAI 等 250+ 成员）。「协议之争」结束，「MCP（Agent→工具）+ A2A（Agent→Agent）」双层栈成为企业参考架构，A2A v1.0 已被 Agentforce / ServiceNow / Google ADK / Azure AI Foundry / Bedrock AgentCore 原生支持；
2. **招聘 JD 已写死双协议**：蚂蚁集团「熟练掌握 LangChain、MCP、A2A 研发架构」（25-50K·15薪）；Sigma Software 架构师岗「在 MCP、A2A、传统 API 之间做架构选型」；
3. Gartner：**40% 企业应用** 2026 年底将含 task-specific Agent。企业 Agent 需要同时消费 MCP 工具层与 A2A 协作层。

**结论**：本框架已有企业级 MCP 全能力（安全/限流/审计/多租户/监控），只差 A2A 这一半。V1.15 补上，且**零成本复用**——工具注册中心一次建设，两种协议消费。

## 二、新增内容

### 1. 新模块 mcp-integrations/mcp-a2a（9 个类，9 个测试全绿）

| 类 | 职责 |
| --- | --- |
| `A2aBridgeService` | 核心桥接：工具注册中心 → Agent Card/Skill 派生；JSON-RPC 分派（message/send、task/send/get/cancel、agent/quote）；任务生命周期（submitted→working→completed/failed/canceled） |
| `A2aRpcController` | A2A HTTP 端点（含 `/.well-known/agent-card.json` 协议标准路径 + `/a2a/agent-card` 别名） |
| `McpA2aAutoConfiguration` | 自动装配（默认关闭 opt-in，`@ConditionalOnProperty`） |
| `McpA2aProperties` | 配置：base-path/api-key/agent-name/task-timeout/max-tasks |
| `A2aAgentCard` / `A2aSkill` / `A2aMessage` / `A2aTask` | A2A 协议数据模型（record） |

### 2. A2A 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/.well-known/agent-card.json` | A2A 标准发现路径（skills 自动派生自 ToolRegistry，仅启用工具） |
| GET | `/a2a/agent-card` | Agent Card 别名 |
| POST | `/a2a/rpc` | JSON-RPC 2.0 分派（含 A2A 标准错误码 -32600/-32601/-32602/-32003/-32004/-32005/-32009） |
| GET | `/a2a/health` | 存活 + 技能数 |

### 3. 调用约定

- `metadata.skillId` = MCP 工具名；`metadata.arguments` = 工具参数（推荐）
- 文本前缀 `tool:<name>` 兜底路由（无 metadata 纯文本通道）
- 一次工具调用 = 一个 Task；结果进入 Artifact（text 序列化，`output` 字段统一）

### 4. 安全

- 默认关闭（`mcp.enterprise.a2a.enabled=false`），未开启不暴露任何 A2A 面
- `api-key` 非空时强制 `X-A2A-Key` 头校验
- 工具调用仍走 `McpToolManager.invoke`（启用校验/审计/统计），A2A 不绕过工具级安全

### 5. 工程接线

- 根 pom 新增 `mcp-integrations/mcp-a2a` 模块；mcp-server 默认引入（可开箱演示）
- Dockerfile 增加 mcp-a2a pom 复制（保持分层缓存）
- mcp-server application.yml 增加 a2a 配置段（`MCP_A2A_ENABLED` / `MCP_A2A_API_KEY` 环境变量注入）
