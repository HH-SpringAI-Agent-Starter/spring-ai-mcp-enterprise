## 二、为什么（市场信号）

1. **证券业招标首次把 MCP Server 工程能力写成供应商资质门槛**：广发证券《2026 年企业微信持续建设项目》征集公告原文要求"MCP Server 设计与开发适配能力（工具定义与描述、参数校验、鉴权与权限控制、调用限流、日志与可观测性）"+多租户数据隔离+防篡改留痕 → 五件套逐条命中 `mcp-core`+`mcp-governance`+`mcp-monitor`+`mcp-tenant`+`mcp-audit`；征集公告=正式招标前 30~60 天卡位窗口。
2. **治理增强层最强量化背书**：趋势科技 TrendAI 报告——19,000 个开源 MCP 仓库 20% 带可利用漏洞、1,467 个对外暴露完全无鉴权、2025 年 95 个 MCP CVE、预估 2026 年 AI CVE 2,800~3,600、RTT（Return-to-Tool）攻击范式 → 两个数字可直接进标书。
3. **网关自身出洞**：CVE-2026-120323（MCPHub）把调用者 Authorization/Cookie/X-Api-Key 透传给攻击者注册的 OpenAPI server → "用了网关≠安全，网关需要治理增强层"新增实证，命中 `mcp-gateway` 的 egress 白名单/准入分级设计。
4. **MCP 成采购与财报级条目**：太平金科智能化研发工作台（MCP/Skills 写进保险业采购功能清单，信创+私有化硬约束）；京北方半年报"提供 MCP 服务"进入上市银行 IT 商财报披露。
5. **招聘密度持续**：国内 4 条（小米 25-30k/Robotaxi 30-60k·16薪/全栈 15-30k/北芯生命）+ 海外 3 条（纽约 Bench Zero Java+Spring AI 合同 12-18 月/GSK 伦敦 FDE/San Jose Elucida build MCP servers）；「写过 MCP 服务吗」进入 Java 后端面试题体系。
