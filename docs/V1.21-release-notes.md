## 二、新增内容

### 1. 新模块 `mcp-registry`（核心代码增量）

纯内存、零外部依赖、线程安全的 Skill 治理层：

- **`SkillRegistry`**：注册（注册即激活）、语义化版本管理、显式激活、**故障回滚（一键退回上一已部署版本）**、**灰度路由（权重制，未分配权重自动回退 ACTIVE）**、版本历史裁剪（max-versions-per-skill）
- **管理端点 `/api/admin/skills`**：列表 / 注册 / 详情 / 版本史 / activate / rollback / gray / DELETE
- **客户端发现端点 `/api/mcp/skills`**：只读，MCP 客户端可读取含 version/status 的 Skill 清单（审计可追溯"结果来自哪个版本"）
- **自动配置**：`mcp.enterprise.registry.skill.enabled=true`（默认启用），Controller 以 @Bean 注册（mcp-a2a 同款模式）
- **12 个单元测试全绿**（注册冲突 409 / 回滚 / 灰度 100% 确定性 / 权重 0 回退 / 历史裁剪 / 删除清理）

### 2. `docs/skill-registry-guide.md` — 使用指南
