# V1.19 发布说明 —— 工具级 Scope 权限映射（Token Scope → Tool ACL）

> 发布日期：2026-09-04
> 核心主题：**「拿到令牌」≠「能调所有工具」** —— OAuth2 token scope 细粒度映射到 MCP 工具级权限，RFC 6750 `insufficient_scope` 语义落地

## 二、新增内容

### 1. `ScopeMatcher`（mcp-core）—— 企业 scope 通配匹配器
- 精确匹配：`tools:finance:read`
- 单段通配 `*`：`tools:finance:*` 命中 read/write/admin
- 多段通配 `**`：`tools:**` 命中 finance/database 任意层级
- 全匹配 `*`：等价不过滤
- 决策语义：任一命中即放行；令牌无 scope + 工具有约束 → 拒绝

### 2. `ToolScopePolicy`（mcp-core）—— 授权策略解析器

**解析优先级（由高到低）：**
1. `ToolDefinition.requiredScopes` —— 工具显式声明（新增字段，setter 链式设置，12 参构造签名不变 → **零破坏**）
2. `toolOverrides` —— 配置按工具名覆盖（运维免改代码）
3. `categoryDefaults` —— 配置按分类兜底（`finance → tools:finance:*`）
4. 均未命中 → 无约束放行（向后兼容）

**授权决策：** 策略 `enabled=false` → 恒放行（与 V1.18 行为完全一致）；启用后按上述规则 fail-closed 拒绝。

### 3. `McpToolManager.invokeWithScope`（mcp-core）—— 执行前强制
- 拒绝时**不触发执行器**（fail-closed，0 次副作用）
- 返回 `{success:false, error:"insufficient_scope", requiredScopes, tokenScopes, httpStatus:403}`
- 旧 `invoke(name, params)` 签名与行为不变（128 个既有测试零回归依据）

### 4. 双通道强制（mcp-server）

| 通道 | 行为 |
| --- | --- |
| `POST /api/mcp/tools/{name}/invoke`（REST） | 拒绝 → **HTTP 403** + `WWW-Authenticate: Bearer error="insufficient_scope"`（RFC 6750 §3.1）+ 审计日志 |
| `POST /api/mcp/v2/tools/call` / `/message`（Streamable HTTP） | 拒绝 → JSON-RPC 错误码 **-32090** `insufficient_scope` + HTTP 403 + `WWW-Authenticate` |
| `tasks/create`（长任务） | **scope 预检**：无权限任务不入队（fail-fast） |

### 5. 能力自描述
- `tools/list` / `tools/discover` 输出 `requiredScopes`（策略启用时）→ **客户端可在令牌签发时就申请正确 scope**
- `GET /api/mcp/scope/policy` 观察端点：开关状态 + 全量工具所需 scope 清单
- `initialize` 能力声明新增 `capabilities.security.scopeEnforcement: true`

### 6. 配置（mcp-server/application.yml）
```yaml
mcp:
  enterprise:
    security:
      scope:
        enabled: true                          # 总开关（默认 false = 向后兼容）
        category-defaults:                     # 分类兜底
          finance: "tools:finance:*"
          database: "tools:database:*"
        tool-overrides:                        # 工具名覆盖（最高优先级除显式声明外）
          finance_indicator: "tools:finance:read"
```
