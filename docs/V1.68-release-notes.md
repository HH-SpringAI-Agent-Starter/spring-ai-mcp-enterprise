| 🆕 [`stdio-command-allowlist/README.md`](../examples/stdio-command-allowlist/README.md) | 六条控制点 / 运行方式 / 对照组断言 / 框架模块对位 / 诚实边界 / 来源 |

**六条控制点**：① 规范化绝对路径白名单（默认空 = 全拒绝）② shell 解释器与内联代码载体黑名单 ③ 参数元字符 / NUL / `--http` / `0.0.0.0` / `--host=` / `--bind=` 逐条扫描 ④ `-c key=value` 只认官方三个安全 git 配置 ⑤ `LD_PRELOAD` / `GIT_CONFIG_*` 等环境变量净化 ⑥ `ProcessBuilder(List)` **argv 数组启动，绝不经过 shell**，每条拒绝带稳定 reason 码可落 `mcp_security_*`。

**实测**（2026-11-10，`javac -encoding UTF-8` + `main()`）：

```
self-test OK (14 attack cases + 7 control cases + 3 boundary assertions)
incremental blocks beyond legacy baseline: 18 checks passed
```

其中 **11 个攻击用例是「只查可执行文件名的旧 allowlist」会放行的增量拦截**；7 个合法用例要求新旧结论一致（**不得劣于既有基线**），3 个边界断言验证 fail-closed / 拒绝 shell / argv 数组。开发过程中断言确实抓到一处 `--host=` reason 码不一致并修正 —— **只看「误报更少」或只看「拦得更多」都会选错方案**。
